# PHASE 05 — Restore Repository-Aware Starter Suggestions in New Feature Mode

**Complexity: EASY**  
**Priority: P2 — Small Frontend Logic Fix**

Repository: [https://github.com/ghazyAlghifari508/everythings-vibe](https://github.com/ghazyAlghifari508/everythings-vibe)  
Branch: `feature/vibeplan-existing-codebase`

## Objective

Perbaiki bug hilangnya starter suggestions/prompt shortcuts ketika user memilih "Buat fitur baru" pada Existing Codebase workspace.

User harus tetap mendapatkan saran fitur berdasarkan repository yang sudah tersinkron dan dianalisis.

**Tidak perlu melakukan sync ulang hanya untuk membuka workspace fitur baru.**

## Confirmed Finding

Di `codebase-chat-workspace.tsx` terdapat:

```
starterSuggestions={
  isCreatingNew ? undefined : starterSuggestions
}
```

Kondisi ini sengaja menghilangkan suggestions ketika `isCreatingNew` bernilai true.

Akibatnya, new feature empty state hanya menampilkan heading dan composer tanpa suggestions.

## Required Investigation

Baca repository rules dan periksa:

- `src/features/codebase/components/chat/codebase-chat-workspace.tsx`
- `src/features/codebase/components/chat/codebase-chat-workspace-pristine.tsx`
- `src/features/codebase/components/workspace/codebase-detail-page.tsx`
- `src/features/codebase/hooks/use-workspace-analysis.ts`
- `src/features/codebase/services/analysis-selection.ts`
- Existing starter suggestions schema dan tests.

Pastikan suggestions berasal dari analysis record milik repository/snapshot yang benar.

## Implementation

1. Remove the inappropriate suppression of starter suggestions in new feature mode.
2. Reuse persisted repository analysis output.
3. Validate the analysis belongs to the active codebase/snapshot.
4. Preserve the existing suggestion data schema.
5. Clicking a suggestion should prefill the composer, not immediately submit or create a feature.
6. Do not automatically regenerate suggestions on every new feature click.
7. Do not require resync.
8. Do not charge AI credits simply for opening new feature mode.
9. When suggestions are genuinely unavailable, present a clean empty state.
10. If an explicit refresh is supported, ensure user understands that it requests fresh suggestions and may invoke AI.
11. Avoid cross-repository or stale-snapshot suggestions.

## Tests
