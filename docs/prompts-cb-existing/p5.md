## 9. Replace Confusing Prompt Availability Copy

Hapus copy:

```
Prompt ini hanya tersedia sekali
di browser tempat ia dibuat.
```

Copy tersebut menjelaskan mekanisme internal, bukan langkah yang harus dilakukan user.

Gunakan state-based presentation.

### State A: New session is ready

Tampilkan prompt lengkap dan tombol Salin.

### State B: Session is being prepared

Tampilkan pesan:

```
Menyiapkan instruksi sync ulang...
```

Tidak ada prompt palsu.

### State C: Credential is unavailable but replacement is allowed

Gunakan:

```
Instruksi sync sebelumnya tidak tersedia.
Buat instruksi baru untuk melanjutkan.
```

Action:

```
[Buat instruksi baru]
```

### State D: Agent is already syncing

Gunakan:

```
Repository sedang disinkronkan.
Pantau progresnya di bawah.
```

Jangan menawarkan penggantian token jika dapat mengganggu upload.

### State E: Session completed

Tampilkan completion yang sudah diverifikasi.

### State F: Session creation failed

Gunakan error message yang menjelaskan tindakan pemulihan. Jangan mengklaim progress sudah selesai.

Semua copy harus mengikuti state dari FIX 04, bukan hanya kondisi `payload === null`.

## 10. Footer Action Semantics

Jangan selalu menampilkan tombol `Selesai`.

Aturan:

- Before starting: `Tutup`.
- Preparing: close control tetap tersedia jika aman.
- Waiting for agent: close dapat tersedia tanpa membatalkan server session secara diam-diam.
- Running: tampilkan status berjalan, tanpa completion palsu.
- Verified completed: `Selesai`.
- Failed: tampilkan recovery action yang sesuai.

`Selesai` hanya boleh menjadi completion action ketika benar-benar selesai.

Jangan memakai label Selesai untuk sekadar menutup modal yang belum melakukan apa pun.
