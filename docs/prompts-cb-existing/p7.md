No visible checkboxes.

No always-visible Select All.

No always-visible Hapus Semua.

No uppercase "EXISTING CODEBASE" eyebrow.

## 4. Selection Entry

User clicks:

```
⋮
│
├─ Ganti nama
├─ Pilih
└─ Hapus project
```

Click "Pilih":

- Enter selection mode.
- Immediately select clicked repository.
- Reveal checkboxes.
- Reveal selection toolbar.
- Disable unintended navigation while selecting.
- Preserve current search/pagination context.

## 5. Active Selection

```
[✓] Pilih semua

[✓] Ghazy Portofolio
[✓] Ocean Guard
[ ] React Movie App

2 repository dipilih

[Batalkan Pilihan] [Hapus Terpilih]
```

Expected:

- Checkbox state consistent.
- Select All semantics clear.
- Filtered selection does not accidentally expand to unrelated repositories.
- Page navigation does not corrupt selected IDs.
- User can exit selection mode.
- Deleting requires proper confirmation.
- Results update from authoritative backend response.
- No duplicate deletion.
- No cross-user deletion.
