- Klik `@` menampilkan panel selebar composer.

Position should follow the actual `@` button, not the entire composer.

The popup should:

- Float above the toolbar.
- Use a compact natural width.

- Not cover large parts of the chat unnecessarily.

## 6. Correct Trigger and Anchor

Use the actual `@` button as trigger or positioning anchor.

Do not use the full composer width as positioning anchor.

Prefer library-supported placement:

- `side="top"` where appropriate.
- Alignment matching the `@` trigger.
- Reasonable `sideOffset`.
- Collision detection.
- Viewport padding.
- Portal layer.

Do not rely on negative offsets to deliberately overlap and obscure composer borders.

The same button should toggle open/close predictably.

Do not create duplicate click handlers that cause immediate open-then-close.

## 7. Search and Empty State

Keep document search functionality.

When no documents exist, show a concise and relevant empty state:

```
Belum ada dokumen planning
Dokumen akan tersedia setelah
PRD, AC, atau Tasks dibuat.
```

Do not display a huge blank panel.

Do not make the empty state full-width.

Do not invent documents.

When documents exist, use their actual names/types.

Example:

```
PRD
Dokumen kebutuhan fitur

Acceptance Criteria
Kriteria penerimaan fitur

Tasks
Daftar pekerjaan
```

These are conceptual examples. The selector must use real planning artifacts for the active feature.
