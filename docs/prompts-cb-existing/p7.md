# FIX 07 — Clean Document Preview &amp; Accessible Kanban Scrolling

**Repository:** `ghazyAlghifari508/everythings-vibe`  
**Branch:** `feature/vibeplan-existing-codebase`

## Objective

Perbaiki dua masalah pada preview panel kanan Existing Codebase:

1. Hilangkan komentar struktural internal dari PRD/AC Markdown preview.
2. Buat horizontal scrolling Kanban mudah digunakan tanpa harus menggulir ke bagian paling bawah task list.

Jangan redesign seluruh preview panel.

## A. Remove Internal Markdown Markers

### Current Problem

Preview menampilkan teks seperti:

```
<!-- SECTION: Overview -->
<!-- /SECTION -->
<!-- SECTION: Design & Technical Constraints -->
```

Marker internal ini tidak boleh terlihat oleh pembaca dokumen.

### Expected

```
1. Overview
   1.1 Latar Belakang
   1.2 Deskripsi Produk

2. Goals & Success Metrics
   ...
```

Tanpa komentar teknis internal.

Investigasi:

- `src/lib/prompts.ts`
- `src/components/codebase/codebase-markdown.tsx`
- `src/components/codebase/codebase-doc-preview.tsx`
- Shared PRD parser, section revision, dan Markdown rendering.

Requirements:

- Hilangkan marker pada presentation layer.
- Pertahankan canonical document dan metadata bila masih diperlukan oleh revision engine.
- Jangan merusak Markdown code fences.
- Jangan menghapus HTML/Markdown secara agresif dengan regex yang bisa menghilangkan konten valid.
- Pertahankan headings, tables, Mermaid, lists, dan syntax highlighting.
- Pastikan copy/download semantics tetap konsisten dan jelas.
- Jangan mengubah data tersimpan secara destruktif hanya untuk memperbaiki preview.

## B. Accessible Kanban Horizontal Scrolling

### Current Problem

Kanban preview memiliki banyak task dan scrollbar horizontal berada di bawah keseluruhan konten, sehingga user harus menggulir sangat jauh untuk mengaksesnya.

### Expected

```
Papan Kanban           [←] [→]

┌───────────┬───────────┐
│ To Do     │ Progress  │
│           │           │
│  Task 1   │  Task A   │
│  Task 2   │           │
│  Task 3   │           │
└───────────┴───────────┘

Navigasi horizontal tetap mudah
diakses ketika list vertikal panjang.
```

Investigasi:

- `src/components/codebase/codebase-kanban-board.tsx`
- `src/components/codebase/codebase-artifact-canvas.tsx`
- Existing scroll container/layout.

Requirements:

- Kanban punya scrolling area yang jelas.
- Tambahkan navigasi horizontal yang accessible jika diperlukan.
- Tombol panah mengikuti posisi scroll yang sebenarnya.
- Wheel vertikal tetap natural.
- Keyboard navigation tetap berfungsi.
- Konten task tidak terpotong.
- Tidak ada nested overflow yang merusak layout panel.
- Responsive untuk panel yang sempit.

## Mandatory Component Discovery

Periksa terlebih dahulu `ScrollArea` dan `ScrollBar` dari shadcn/ui, serta komponen scroll siap pakai dari HeroUI.

Eksplor Magic UI dan React Bits jika membutuhkan subtle interaction feedback, bukan untuk dekorasi.

**Gunakan komponen siap pakai yang sesuai. Jangan membuat scroll system dari nol apabila existing ScrollArea bisa memenuhi kebutuhan.**

## Tests &amp; Completion

Uji Markdown sanitization/presentation, preservation of original content, dan scroll helper logic yang relevan.

Jalankan unit tests, typecheck, lint, build.

Tidak melakukan browser QA, browser E2E, Playwright, Puppeteer, atau screenshot testing.

Commit dan push sesuai [`AGENTS.md`](http://AGENTS.md).

**Definition of Done:** preview dokumen tidak memperlihatkan komentar internal, dan Kanban dapat dinavigasi horizontal tanpa harus turun ke akhir daftar task.
