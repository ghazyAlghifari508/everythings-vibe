## 3. Header: Repository Name Without Badge

Current structure:

```
[everything-vibe Logo] / [ Ghazy Portofolio ]
```

Nama repository berada di dalam kotak dengan border, background, padding, dan radius.

Ini tidak diperlukan karena nama repository bukan status, kategori, atau tag.

Target:

```
[everything-vibe Logo] / Ghazy Portofolio
```

Implementasikan:

- Logo tetap menggunakan reusable Logo component.
- Separator `/` tetap jelas.
- Nama repository menjadi plain text.
- Hilangkan border, background, padding card, dan radius dari wrapper nama repo.
- Gunakan font yang konsisten dengan header.
- Pertahankan truncation untuk nama panjang.
- Jangan mengubah nama repository yang tersimpan.
- Jangan membuat badge dengan warna berbeda sebagai pengganti.

Jika nama repository panjang:

- Jangan biarkan header overflow.
- Gunakan ellipsis yang layak.
- Jika perlu, gunakan Tooltip siap pakai untuk menampilkan nama lengkap, bukan custom tooltip baru.
- Jangan menyembunyikan tombol Sync ulang atau informasi file sync.

## 5. Sidebar Technology Label

Current:

```
STACK CODEBASE TERDETEKSI

[Astro] [Tailwind CSS] [TypeScript]
```

Recommended:

```
TEKNOLOGI PROYEK

[Astro] [Tailwind CSS] [TypeScript]
```

Gunakan copy:

```
Teknologi proyek
```

Alasan:

- Lebih natural dalam Bahasa Indonesia.
- Tidak perlu mengulang istilah "codebase".
- Tidak perlu menyatakan bahwa teknologi "terdeteksi" ketika daftar sudah terlihat.
- Tetap mudah dipahami developer maupun pengguna nonteknis.

Pertahankan data stack yang berasal dari detection aktual.

Jangan hardcode daftar teknologi.

Jangan mengubah detection engine.

Jangan menghapus teknologi dari daftar demi estetika.

Jika tidak ada teknologi yang dapat diidentifikasi, gunakan pesan:

```
Teknologi belum teridentifikasi
```

Jangan menampilkan data fiktif.

Penyajian teknologi boleh mempertahankan chips yang sudah tersedia selama tidak menambah dekorasi yang tidak diperlukan. Pengguna hanya meminta label bagian ini diperbaiki, bukan menghapus kemampuan melihat teknologi.

## 8. Cross-Surface Consistency

Periksa label dan separator terkait pada Existing Codebase yang relevan.

Aturan:

- Gunakan `/` untuk breadcrumb atau hierarki navigasi.
- Gunakan `|` untuk pemisah metadata inline.
- Gunakan heading dan subtitle terpisah bila informasinya mempunyai hierarki.
- Jangan menggunakan middle dot hanya karena terlihat minimal.
- Jangan mengganti em dash dengan middle dot.
- Jangan membuat badge untuk informasi yang sebenarnya plain text.
- Jangan mengubah teks pada halaman lain di luar scope.

Contoh:

```
Navigasi:
everything-vibe / Ghazy Portofolio

Metadata:
Astro | TypeScript | npm

Heading:
Ghazy Portofolio
Workspace perencanaan
```

Jangan menerapkan satu separator untuk semua konteks tanpa memahami artinya.
