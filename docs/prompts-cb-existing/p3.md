## 3. Remove Redundant "Siap"

Untuk repository yang dalam kondisi normal dan dapat dibuka, hilangkan teks `Siap` dari card.

Jangan menggantinya dengan:

- Aktif
- Ready
- Selesai
- Tersedia
- Connected
- Badge berwarna hijau

Status normal tidak memerlukan ornamen tambahan.

Status hanya perlu ditampilkan jika memberikan informasi yang berguna, misalnya:

- Perlu analisis.
- Sinkronisasi gagal.
- Membutuhkan tindakan pengguna.
- Kondisi pemulihan lain yang benar-benar didukung state.

Jangan menyembunyikan actionable errors.

Jangan menonaktifkan state machine atau mengganti return value `resolveLibraryItemStatus()` hanya agar teks hilang.

Jika logika status digunakan di komponen lain, lakukan perubahan presentasi pada card atau abstraction yang tepat tanpa merusak consumer lain.

## 4. Replace Metadata Separators

Gunakan separator `|` untuk metadata inline yang relevan.

Before:

```
Astro · TypeScript · npm
```

After:

```
Astro | TypeScript | npm
```

Before:

```
69 file · 2 fitur plan · Terakhir diperbarui 9 Nov 2026, 00.27
```

After:

```
69 file | 2 rencana fitur | Diperbarui 9 Nov 2026, 00.27
```

Ketentuan:

- Gunakan separator konsisten.
- Jangan menggantinya dengan em dash.
- Jangan menggunakan middle dot, bullet dot, atau karakter serupa.
- Jangan menggunakan separator ganda ketika data kosong.
- Jika metadata tertentu tidak tersedia, tampilkan bagian yang memang ada.
- Jangan membuat placeholder palsu hanya agar layout terlihat penuh.
- Gunakan format tanggal Indonesia yang benar.
- Jangan hardcode tanggal, jumlah file, stack, atau jumlah fitur.

Utamakan pemisahan metadata yang semantik dan reusable daripada melakukan string replacement sembarangan pada seluruh proyek.

Scope penggantian hanya tampilan history yang relevan. Jangan melakukan global replacement terhadap karakter yang mungkin dipakai untuk tujuan berbeda.
