## 4. EXACT REQUIRED COPY — DO NOT CHANGE WORDING

Semua teks berikut disediakan secara eksplisit.

**Jangan meminta AI menciptakan ulang copywriting.**

### State A — Prompt Not Available, Sync Not Started

Heading:

```
Lanjutkan sinkronisasi
```

Description:

```
Prompt sebelumnya tidak tersedia lagi setelah halaman ditutup. Buat prompt baru untuk melanjutkan repository ini.
```

Primary action:

```
Buat prompt baru
```

Supporting note, hanya jika akan mengganti credential yang sebelumnya mungkin sudah disalin:

```
Prompt sebelumnya tidak berlaku setelah diganti.
```

Jangan menggunakan:

- "Token sebelumnya hanya dikirim sekali".
- "Buat sesi pengganti".
- "Token sebelumnya akan dinonaktifkan".
- "Recovery required".
- "Coba lagi" untuk normal recovery.
- "Generate credential".
- "Perbarui otorisasi".
- "Restore session".
- "Tindakan tidak dapat dilanjutkan" jika sistem sebenarnya bisa melanjutkan.

### State B — Session Expired Before CLI Started

Heading:

```
Sesi sinkronisasi berakhir
```

Description:

```
Buat prompt baru untuk melanjutkan sinkronisasi repository ini.
```

Action:

```
Buat prompt baru
```

No unrelated technical explanation.

### State C — Replacement In Progress

Label:

```
Menyiapkan prompt baru...
```

Show spinner only while server request is genuinely pending.

No fake animation delay.

### State D — Prompt Successfully Replaced

Return to normal prompt display:

```
1  Salin instruksi untuk AI agent

   [Real CLI prompt content]

   [Salin]
```

Remove recovery message.

No success card required.

No unnecessary toast unless the existing interaction requires one.

### State E — Genuine Replacement Error

Title:

```
Prompt belum berhasil dibuat
```

Description:

```
Permintaan belum berhasil. Coba buat prompt lagi.
```

Action:

```
Coba lagi
```

Only use this state when the server actually failed.

Do not misuse it for a valid session that simply cannot return the original credential.

### State F — CLI Already Active

Copy:

```
Agent sedang menyinkronkan repository.
```

Do not offer replacement of an active session.

### State G — Upload Completed

Copy:

```
Source code berhasil diterima.
```

Let analysis progress carry the next step.

No requirement for another CLI prompt.

### Visual Rules

- Content left-aligned.
- Heading aligned with description and action.
- No centered narrow paragraphs.
- No giant empty space.
- Natural padding consistent with existing prompt container.
- Use existing typography scale.
- Keep reasonable maximum text width.
- Use consistent button sizing.
- Use current dark-mode palette.
- No extra wrapper card.
- No decorative icon needed unless existing component already has one and it adds meaning.
- No red error background for normal recovery.
- No full-screen overlay.
- No modal.
- No arbitrary new gradients or shadows.

If existing prompt container already has border and background, reuse it without nesting another large card.
