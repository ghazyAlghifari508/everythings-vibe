## Target UX

### Chat artifact

```
┌─────────────────────────────────┐
│ ▤ PRD · Pencarian Artikel   →   │
│   Dokumen siap                  │
└─────────────────────────────────┘
```

Click → membuka preview di panel kanan.

### Right preview

```
┌─────────────────────────────────┐
│ PRD · Pencarian Artikel  ⧉ ↓ × │
├─────────────────────────────────┤
│                                 │
│ 1. Overview                     │

│                                 │
│ Isi PRD...                      │
│                                 │
└─────────────────────────────────┘
```

Toolbar:

- Copy.
- Download.
- Close.

Gunakan icon-only dengan tooltip dan accessible labels.

## Requirements

1. Hilangkan tombol "Unduh" besar dari setiap file card di chat.
2. File card tetap clickable dan membuka artefak yang benar.
3. Download tetap tersedia di toolbar preview.
4. Copy mengambil konten dokumen yang benar.
5. Jangan tampilkan "Ukuran menyusul" ketika ukuran tidak tersedia.
6. Jika ukuran tersedia dari data nyata, tampilkan secara benar; jika tidak, omit.
7. Hindari nama file panjang yang merusak layout. Gunakan truncation dan akses ke nama lengkap melalui title/tooltip.
8. Jangan menduplikasi informasi seperti "Markdown", "Dokumen PRD", dan nama file apabila tidak membantu user.
9. Pertahankan existing `.md` / `.json` download behavior dan nama file yang benar.
10. Pertahankan CLI export/handoff terpisah untuk ekspor seluruh planning.

Jangan menampilkan placeholder metadata palsu.

Jangan mengubah canonical PRD/AC content atau Task JSON hanya untuk memperbaiki UI.

## Verification

Uji:

- File card membuka preview.
- Copy menyalin konten valid.
- Download menghasilkan file yang benar.
- Metadata yang tidak tersedia tidak ditampilkan.
- Long filename tidak memecahkan layout secara struktural.
- Tidak ada duplicate download action.
- Failed/loading artifact tidak mengunduh file kosong.
- Existing export/handoff tetap berfungsi.

Jalankan unit/component tests non-browser, lint, typecheck, dan build.

**Skip browser QA, Playwright, Puppeteer, manual browser testing, dan screenshot testing.**

## Definition of Done

Chat hanya menampilkan artefak yang mudah dibuka, preview menjadi lokasi utama Copy/Download, dan tidak ada metadata placeholder atau tombol yang berulang tanpa kebutuhan.
