## Objective

Refine the existing VibeDesign Studio landing layout without redesigning it.

The current landing page already has a good visual direction inspired by Google Stitch:

- Dotted canvas background.
- Floating project history sidebar.
- Large, lightweight hero typography.
- Prominent prompt composer.
- Horizontal shortcut cards.
- Floating logo and user profile.

**Preserve these successful design decisions.**

The actual problem is layout geometry, spacing, and viewport utilization.

### User-reported problems

1. The project sidebar is too far from the browser's left edge.
2. The hero and prompt composer still leave excessive unused space on the right.
3. Header, sidebar, and main content do not feel aligned to a consistent spatial system.
4. The page should feel balanced and efficient, similar to Google Stitch, rather than artificially constrained inside a centered container.

**Do NOT redesign the landing page from scratch.**

## Implementation Requirements

### 1. Sidebar positioning

- Move the floating sidebar slightly closer to the viewport's left edge.
- Use a consistent outer gutter shared with the header/logo.
- Preserve the sidebar's stable viewport-relative height.
- Preserve rounded corners, background, border, search, and project history.
- Avoid touching history behavior or deletion logic.
- Do not make the sidebar full-height edge-to-edge.

### 2. Main content width

- Increase the effective horizontal space available to the hero, composer, and shortcut carousel.
- Keep the composer readable and intentionally proportioned.
- Avoid excessive max-width constraints that produce unused right-side space.
- Keep the heading, subtitle, composer, and shortcut section aligned along the same left edge.
- Do not stretch text into excessively long line lengths.
- Make width adapt gracefully from laptop to ultrawide desktop.

### 3. Shared alignment system

Use one coherent layout system.

Prefer grid/flex with deliberate columns and gutters:

```
Viewport
   |
   ├── Outer Gutter
   |
   ├── Fixed/Responsive Sidebar Column
   |
   ├── Consistent Column Gap
   |
   └── Flexible Main Content Column
```

Do not solve spacing with arbitrary negative margins, absolute-position offsets, or viewport-specific magic numbers.

### 4. Preserve styling

Do NOT arbitrarily change:

- Hero font family, size, or weight.
- Dotted background.
- Composer styling.
- Existing buttons.
- Skill selector.
- Prompt shortcuts.
- Brand logo.
- User avatar.

These elements are already acceptable; the task is layout geometry.
