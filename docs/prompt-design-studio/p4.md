## Objective

Improve the existing project history card UI in VibeDesign Studio.

Current problems:

- Project action menu uses horizontal ellipsis (`...`) instead of vertical ellipsis.
- Desktop/Mobile platform icon appears visually detached from the action menu.
- Different title lengths produce inconsistent icon alignment.
- Some labels and generated UI copy use undesirable em dash punctuation.
- User wants a compact, professional project-history row similar to established SaaS sidebar patterns.

3. Preserve title wrapping to two lines without changing action positions.
4. Align Web/Mobile icon and ellipsis vertically.
5. Keep button sizes, hit targets, and spacing compact.
6. Preserve hover, focus, open-menu, and disabled/deleting states.
7. Preserve project navigation, delete confirmation, search, and scrolling.
8. Avoid layout movement when dropdown opens or the project title changes.
9. Preserve accessibility labels.

### Em dash policy

For newly authored or revised public-facing Studio UI copy, **do not use em dash (**`—`**)**.

Use a normal colon, comma, period, middle dot, or separate text elements where appropriate.

However, **do not mutate project names entered by users or stored in existing history just because they contain an em dash**. User-owned text must remain intact.

If auto-generated project titles use em dashes as formatting, inspect the actual title-generation rule before deciding how to correct future titles. Do not corrupt historical data.
