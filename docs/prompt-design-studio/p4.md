# FIX 04 — Remove Redundant Frame Header Loading Indicator

**Complexity: SIMPLE | Priority: P2 | Scope: Studio frame loading UX**

Kerjakan setelah FIX 03.

## Masalah

Saat frame sedang digenerate, muncul ikon spinner di samping nama frame. Sementara artboard sudah menggunakan shimmer besar sebagai indikator bahwa proses masih berjalan.

User tidak menginginkan dua indikator visual yang menyampaikan informasi sama.

Lokasi utama:

`src/features/studio/components/canvas/studio-frame.tsx`

Audit juga:

- `studio-frame-shimmer.tsx`
- `studio-frame-error.tsx`
- `studio-frame-artboard.ts`
- Tests terkait status frame.

## Perbaikan

Hapus loading spinner visual `Loading03Icon` dari header ketika `frame.status === "generating"`.

Pertahankan:

- Nama frame.
- Ikon platform web/mobile jika memang diperlukan.
- Satu shimmer pada area artboard yang belum siap.
- Status aksesibel untuk screen reader.
- Penanganan antrean.
- Error dan retry asli.
- Existing HTML saat revisi berjalan, jika memang sistem mempertahankan last-good preview.

Jangan mengganti spinner dengan badge, blinking dot, fake progress bar, countdown, atau animasi pengganti.

Jangan menghilangkan informasi kegagalan hanya karena user meminta spinner dihapus.

## Visualisasi

Sebelum:

```
[ Mobile Icon ] Eksplorasi Menu  [spinner]

+------------------------------+
|                              |
|         SHIMMER              |
|                              |
+------------------------------+
```

Sesudah:

```
[ Mobile Icon ] Eksplorasi Menu

+------------------------------+
|                              |
|     SINGLE FRAME SHIMMER     |
|                              |
+------------------------------+
```

## Ketentuan UI

Reuse existing `StudioFrameShimmer`. Jangan membuat komponen loading baru.

Jika benar-benar perlu komponen tambahan, lakukan discovery pada existing shared UI, HeroUI, shadcn, TUFFUI, Thinking Orbs, dan library yang tersedia, tetapi jangan memakai komponen hanya untuk menambah dekorasi.

## Acceptance criteria

- Tidak ada spinner berputar di samping nama frame saat generating.
- Shimmer tetap tampil pada artboard pending.
- Ready frame menampilkan visual.
- Failed frame tetap menunjukkan recovery yang tepat.
- Accessible status tetap ada tanpa duplikasi pengumuman yang tidak perlu.
- Tidak ada perubahan pada job lifecycle.
- Targeted tests berhasil.

Jangan menjalankan browser QA atau Playwright E2E.

Lakukan perubahan sekecil yang diperlukan, lalu laporkan file yang diubah dan hasil tes.
