# FIX 06 — Align Studio History Empty State With Project List Layout

**Complexity: SIMPLE | Priority: P2 | Scope: Studio project history sidebar**

Kerjakan setelah FIX 05.

## Masalah

Saat history kosong, sidebar menampilkan:

"Belum ada project studio."

"Tulis deskripsi antarmuka di samping untuk memulai."

Masalahnya adalah teks berada di tengah seluruh tinggi sidebar, sedangkan project history cards muncul dari atas.

Ini membuat posisi konten sidebar terasa tidak konsisten.

Lokasi utama:

`src/features/studio/components/workspace/studio-sidebar.tsx`

Periksa juga mobile history drawer dan tests terkait.

## Solusi

Ubah empty state agar mengikuti area awal daftar history, yaitu tepat setelah search field.

Tidak perlu memenuhi tengah sidebar yang tinggi.

Gunakan teks yang lebih natural:

**Belum ada proyek**

"Desain yang kamu buat akan muncul di sini."

Tambahkan ikon folder outline kecil apabila sesuai dengan existing design system.

Jangan menambah tombol "Buat Proyek" karena main composer sudah menjadi entry point untuk membuat proyek.

## Component discovery wajib

Audit existing shared components dan katalog:

- shadcn/ui Empty.
- TUFFUI Empty State.
- HeroUI components.
- affectUI / SakaniUI jika relevan.
- Library lain yang sudah tersedia dalam proyek.

Reuse atau adapt component/pattern siap pakai yang paling sesuai dengan dark UI EvVibe.

Jangan membuat empty state custom dari nol jika komponen existing sudah memenuhi kebutuhan.

## Bedakan dua empty states

**History benar-benar kosong:**

"Belum ada proyek"

"Desain yang kamu buat akan muncul di sini."

**History ada tetapi pencarian tidak cocok:**

"Tidak ada proyek yang cocok."

Sediakan cara menghapus query pencarian melalui kontrol yang sudah ada, bukan mencampurkan kedua pesan.

Jika history memiliki proyek, cards tetap muncul dari atas tanpa perubahan perilaku.

Perhatikan mobile drawer agar pesan tetap natural dan tidak merujuk pada "di samping", karena mobile menggunakan tata letak berbeda.

## Acceptance criteria

- Empty state berada dekat bagian atas daftar.
- Tidak ada vertical-centering yang menyebabkan posisi pesan aneh.
- History cards tetap memiliki layout existing.
- Search empty state dibedakan dari no-history state.
- Tampilan desktop/mobile tetap konsisten.
- Tidak ada tombol atau UI tambahan yang tidak diperlukan.
- Tests terkait sidebar berhasil.

Jangan browser QA atau Playwright E2E. Kerjakan focused change dan laporkan hasilnya.
