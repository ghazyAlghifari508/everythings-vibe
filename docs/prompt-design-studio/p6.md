# TASK 06 — Repair Theme Toggle Selection, Explicit Deselect, and Remove "Lepas Referensi"

**Kategori:** MEDIUM  
**Prioritas:** P1  
**Repository:** ghazyAlghifari508/everythings-vibe

## TUJUAN

Perbaiki mekanisme pemilihan tema pada fullscreen Design Picker.

Masalah nyata:

1. Tema yang sudah dipilih tidak bisa dibatalkan dengan klik ulang.
2. Ketika pilihan kosong, tombol `Gunakan Tema` menjadi disabled.
3. Tulisan dan tombol `Lepas referensi` masih muncul meskipun sebelumnya sudah diminta dihapus.
4. User tidak ingin action khusus untuk menghapus tema.
5. User ingin mengklik card yang terpilih sekali lagi untuk melakukan deselect.

## SOURCE ROOT CAUSE

Periksa:

```
studio-design-picker-dialog.tsx
studio-design-picker-panels.tsx
studio-generation-options.ts
```

Sebelumnya ditemukan:

```
const [pendingThemeId, setPendingThemeId] =
  useState<string | null>(null);

const activeThemeId =
  pendingThemeId ?? selectedThemeId;
```

Masalah:

`null` dipakai sekaligus sebagai "belum diubah" dan "tidak memilih tema".

Ini tidak cukup untuk membedakan dua intent yang berbeda.

Juga ada:

```
onClick={() => onSelectTheme(preset.id)}
```

Yang selalu memilih tema tanpa toggle.

Dan:

```
disabled={!activeThemeId}
```

Yang menyebabkan clear selection tidak dapat diterapkan.

Jangan mempertahankan ketiga masalah tersebut.

```

```

Gunakan discriminated union atau struktur lain yang benar-benar dapat membedakan ketiganya.

Jangan menggunakan `null` untuk dua makna bertentangan.

## APPLY / CANCEL

```
Open Design Picker
        |
        v
Modify Draft Selection
        |
   +----+----+
   |         |
   v         v
 Cancel    Apply
   |         |
   v         v
Discard   Commit New State
Draft
```

Cancel tidak boleh mengubah pilihan yang sudah diterapkan ke composer.

Apply pada state kosong harus benar-benar menghapus design reference, bukan hanya mengubah border.

Jika user memakai [DESIGN.md](http://DESIGN.md) custom atau VibeScrape reference, jangan menghapus file/metadata lain tanpa kebijakan yang jelas.

PRD `.md` di composer tidak boleh ikut terhapus saat tema dibatalkan.
