# FIX 06 — Replace Three Separate Theme Dots with One Multicolor Circular Palette

**Severity:** P2  
**Complexity:** SMALL  
**Target:** `feature/vibedesign-design-studio`  
**Execution order:** 06/08. Execute after FIX 05.

## Problem

The active design reference displayed inside the canvas composer currently uses three tiny independent colored dots.

This is not what the user requested.

The user wants **one circular multicolor palette icon** containing the selected theme's colors, resembling the visual treatment used by Google Stitch.

Previous audit identified this inside `src/features/studio/components/composer/studio-composer.tsx`, using `resolvedColors.slice(0, 3)` and repeated small circles.

Verify latest source before modifying.

## Visual contract

**WRONG:**

```
┌─────────────────────────┐
│ ● ● ●  Amber            │
└─────────────────────────┘
```

**EXPECTED:**

```
┌─────────────────────────┐
│ [◉]  Amber              │
└─────────────────────────┘
```

Here `[◉]` represents a **single circle divided into several color segments**, not separate dots or a monochrome icon.

Suggested appearance:

```
     _______
   / A | B \
  |----+----|
   \ C | D /
     ‾‾‾‾‾‾‾

One circular palette icon
A / B / C / D = actual theme colors
```

Do not literally put letters or divider lines inside the final circle. The drawing only explains the segmentation.
