# TASK 09 — Remove Redundant Add-Screen Success Toast from Studio Canvas

**Priority:** P2  
**Complexity:** EASY  
**Branch:** `feature/vibedesign-design-studio`

## Objective

Remove redundant informational/success toasts when the user requests a new screen through the Studio canvas composer.

Current messages include:

- "Halaman baru sedang dibuat."
- "2 halaman baru sedang dibuat."

These are unnecessary because the new frame and its loading state already communicate progress directly on the canvas.

## Investigation

Read repository rules and inspect:

`src/features/studio/hooks/use-studio-workspace-actions.ts`

Also inspect the relevant composer submission handler and existing toast system.

Identify the exact toast invocation for a successfully queued `add_screen` operation.

## Requirements

Remove only redundant success/information messages tied to successful add-screen submission.

Preserve:

- Error toasts when submission fails.
- Authentication/session errors.
- Network errors.
- Retry feedback where genuinely needed.
- Frame-specific error states.
- Duplicate submission prevention.
- Button loading/disabled states.
- The actual add-screen backend operation.

Do not change the AI generation logic.

Do not change how frames are queued, persisted, or displayed.

Do not remove the global toast system.

Reuse the existing composer and frame status components.

If a related control requires adjustment, explore existing suitable shadcn/ui, HeroUI, Magic UI, React Bits, Thinking Orbs, or AffectUI components rather than creating new controls.

Avoid introducing another redundant status indicator.

Run relevant tests and typecheck.
