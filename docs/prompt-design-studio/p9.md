Perbaiki tiga hal kecil yang masih mengganggu pengalaman pengguna Studio:

## PART 1 — THEME CHIP

Saat ini terdapat penggunaan:

```
<Icon icon={FileCodeIcon} />
```

Di chip referensi desain dalam composer Studio.

Padahal user memilih theme seperti:

- Workspace.
- Editorial.
- Midnight.
- Jade.
- Orchid.
- Rose.
- Amber.
- Arctic.
- Graphite.

Icon file generik tidak sesuai.

### CURRENT

```
┌────────────────────┐
│ [File Icon] Orchid │
└────────────────────┘
```

### TARGET

```
┌────────────────────────────┐
│ [◯◯◯ Palette]  Orchid      │
└────────────────────────────┘
```

Gunakan tiga swatch warna kecil yang mewakili token tema.

Contoh:

```
Orchid:
Canvas    #F8F5FF
Primary   #7C3AED
Ink       #2E1B4B
```

Persyaratan:

- Ambil nilai warna dari preset/token yang sebenarnya.
- Jangan membuat hardcoded mapping baru yang terpisah dari registry tema.
- Mendukung semua sembilan tema.
- Menjaga nama tema tetap terbaca.
- Chip tetap compact.
- Tidak ada swatch besar yang membuat composer menjadi tinggi.
- Tidak ada icon file untuk built-in palette.

Jika reference berupa VibeScrape atau custom [DESIGN.md](http://DESIGN.md):

- Gunakan palette tokens yang berhasil diekstraksi.
- Jika tidak tersedia atau tidak valid, gunakan fallback icon palette yang netral dan jujur.
- Jangan mengarang warna theme.
- Jangan mengubah data reference hanya untuk keperluan presentasi.
