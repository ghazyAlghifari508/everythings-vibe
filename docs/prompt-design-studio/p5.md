# TASK 05 — Fix Canvas Mouse Wheel Zoom, Pointer-Centered Scaling, and Pan on Frame Surfaces

**Kategori:** MEDIUM–COMPLEX  
**Prioritas:** P1  
**Repository:** ghazyAlghifari508/everythings-vibe

## MISSION

Perbaiki interaksi canvas VibeDesign Studio agar user dapat melakukan zoom in, zoom out, dan pan dengan nyaman meskipun mouse pointer berada tepat di atas frame/preview.

Saat ini gesture lebih mudah berfungsi pada background canvas, tetapi bermasalah saat pointer berada di atas frame.

## ROOT CAUSE YANG PERLU DIVERIFIKASI

File terkait:

```
src/features/studio/hooks/use-studio-canvas-input.ts
src/features/studio/utils/studio-canvas-gesture.ts
src/features/studio/components/canvas/studio-frame.tsx
src/features/studio/components/canvas/studio-canvas.tsx
```

Source sebelumnya menunjukkan:

- Preview frame dibungkus elemen `<button>`.
- `isScrollableOrEditableTarget()` mengecualikan target yang berada di dalam tombol.
- Wheel handler canvas menggunakan hasil fungsi tersebut untuk memutuskan apakah zoom boleh diproses.

Ini menjelaskan mengapa wheel di atas preview dapat diabaikan.

Untuk pan/drag, audit pointer propagation dan capture secara terpisah. Jangan menganggap akar masalah drag otomatis sama dengan zoom.

## EXPECTED BEHAVIOR

### TOOL: SELECT

```
Pointer on background:
  Click -> Clear selection
  Drag -> Marquee selection
  Wheel -> Zoom canvas

Pointer on frame:
  Click -> Select frame
  Wheel -> Zoom canvas
```

### TOOL: HAND

```
Pointer on background:
  Drag -> Pan canvas
  Wheel -> Zoom canvas

Pointer on frame:
  Drag -> Pan canvas
  Wheel -> Zoom canvas
```

Jangan mengubah frame menjadi tidak dapat dipilih hanya demi memperbaiki pan.

## REQUIREMENTS

1. Zoom bekerja di background dan preview frame.
2. Zoom berpusat pada posisi pointer, bukan selalu titik tengah canvas.
3. Pan bekerja ketika Hand tool aktif walaupun pointer berada di frame.
4. Select mode tetap dapat memilih frame.
5. Marquee selection yang sudah ada tidak rusak.
6. Input, textarea, select, modal, dropdown, dan interactive controls tetap dapat menerima event normal.
7. Mouse wheel tidak menyebabkan vertical page scroll ketika gesture memang ditujukan untuk zoom canvas.
8. Perhatikan passive/non-passive wheel listener secara benar.
9. Gunakan `preventDefault()` hanya ketika event memang dikonsumsi sebagai canvas zoom.
10. Hindari double-handling wheel events.
11. Zoom tetap dalam batas minimum/maksimum.
12. Zoom dan pan tidak menghasilkan pointer jumps.
13. Event listeners dibersihkan saat unmount.
14. Tidak ada memory leak.
15. Jika menggunakan pointer capture, release dengan benar pada cancel/up.
16. Jangan menambahkan shortcut yang berbenturan dengan shortcut input text.
