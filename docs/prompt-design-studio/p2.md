# TASK 02 — Improve Design Skill Dropdown Descriptions &amp; Tooltips

**Complexity:** EASY  
**Priority:** P3  
**Branch:** `feature/vibedesign-design-studio`

## Problem

In VibeDesign Studio, the Design Skill dropdown truncates descriptions.

Examples:

- "AI merancang tanpa panduan desain ta..."
- "Untuk desain yang lebih rapi, detail, dan ..."
- "Untuk navigasi, kemudahan penggunaa..."

Users cannot fully understand which skill fits their needs.

Previous source inspection found:

`src/features/studio/components/composer/studio-skill-select.tsx`

```
<span className="mt-0.5 block truncate text-xs text-fog">
  {skill.description}
</span>
```

Verify the latest implementation.

## Objective

Keep the dropdown compact while making the full description accessible.

## Requirements

1. Read repository rules first.
2. Inspect current `StudioSkillSelect` and skill metadata.
3. Prefer wrapping descriptions to a maximum of two lines.

5. Support pointer hover and keyboard focus.
6. Preserve menu keyboard navigation.
7. Preserve verified skill logos and fallback icons.
8. Keep the dropdown scrollable and inside viewport bounds.
