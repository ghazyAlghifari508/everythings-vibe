# P2 implementation report

## Ownership

Previously the frame prompt forbade authored chrome; Studio stripped duplicate model chrome and installed fixed platform bars, rendered legacy `ctaDestination` as a filled website action, and capped mobile composition at phone width on wide viewports. New plans use `compositionOwner: "model"`. Screen/destination mappings, contextual parents, current state, optional primary action and shared identity remain validated; the model owns chrome and component geometry. No mandatory header, sidebar, tab set or link count. Native HTML remains static; external component catalogs are not part of the runtime.

The existing structural diagnostics, card-wall check, theme precedence and bounded correction remain. Semantic frames receive shared variables, low-specificity containment and focus defaults without global card sizes, fixed mobile width, or page-level overflow hiding. Historical projects continue on the canonical path without migration; new committed documents are read directly by preview and export. Revision correction still preserves committed context.

## Photography

The existing planning request describes up to three photos per screen; no extra model request. Resolution runs **beside** generation: the prompt only describes the named slots, so a slow provider no longer delays the model request at all. It reuses the DNS-pinned `fetchAsset` transport, scopes credentials to their own request, refuses redirects, and validates result shape, title/caption relevance, provider-owned URLs, MIME, byte size and JPEG geometry.

Providers, in order. [Openverse](https://docs.openverse.org/) is the keyless default and needs no credential at all; its terms require attribution to the work and a visible notice that Openverse was used, both carried by the credit block beside the image. Pexels is optional and preferred when `STUDIO_PEXELS_API_KEY` is set, because its library needs no attribution ([Pexels API](https://www.pexels.com/api/documentation/), [terms](https://www.pexels.com/terms-of-service/), [cache guidance](https://help.pexels.com/hc/en-us/articles/900006470063-What-steps-can-I-take-to-avoid-hitting-the-rate-limit)). A provider that timed out, ran out of budget or was busy is not retried against the next one, so a slow answer never spends the frame budget twice.

Licence filter, deliberately narrow: `cc0,pdm,by`. Share-alike (`by-sa`) and non-commercial (`by-nc`) are excluded so a generated design never inherits a redistribution obligation, and only JPEG bytes that pass a size and dimension check are used, which rejects SVG and placeholder thumbnails. Quotas are honoured locally: Openverse 20/min burst and 200/day published, 18/min and 180/day enforced; Pexels 200/hour and 20,000/month published. Metadata is cached for 24 hours and in-flight lookups are shared by query and aspect. Photo binaries are never redistributed inside a ZIP; export lists the external dependency, so a stock photo needs connectivity. Supplied local assets keep their existing bundling path. Neither provider warrants third-party rights, and exact client work, branded products, book covers or portraits of specific people still require a supplied asset.

Alternatives rejected: Unsplash and Pixabay both need an issued key (Unsplash demo is 50 requests/hour and mandates hotlinking; Pixabay forbids permanent hotlinking and caps at 100 requests/60 s), and [new Pexels key issuance is paused and cannot be requested](https://www.pexels.com/api/), which is why the keyless provider is the default rather than the fallback. Pexels does not require attribution, though Studio credits it anyway.

The model positions named slots. Studio fills them with a verified image or a neutral, sized fallback with a recorded reason. Unknown image references are rejected rather than fetched. Capture revalidates the served image. An image removed by the provider after generation can still degrade a later preview/export; there is no offline stock mirror.

## Performance and verification

Live, no credential. An Openverse query that its own index had not cached answered 504, then 500, then 200 across 11.9-15.2 s, and the same query answered in 59 ms once warm, so the deadline is 25 s, a 5xx earns one bounded retry, and resolution runs beside generation instead of before it. End to end with no key: three planning queries resolved real photographs (a CC0 image in 0.58 s, two CC BY 2.0 images in 16.2 s and 0.30 s) carrying creator, licence name and licence URL, and a sample document placed the image with an empty issue list, the licence link beside the credit and the external dependency listed for export. Openverse publishes no orientation parameter (an unknown value silently returns zero results), so the requested aspect is enforced from the verified pixel geometry, and alt text comes from the plan's subject intent rather than a filename-like provider slug. Anonymous budget: published 20 requests/minute and 200/day. A Pexels CDN sample: JPEG 33,775 bytes, validated at 650 × 650 in 108 ms including transport and validation (transport alone 367 ms), with a 2.8 s deadline. Candidates per search are bounded (four Pexels, five Openverse). Photo failures do not consume correction attempts. Runtime logs record each provider verdict and the resolved provider. Measured two-screen travel planning request: 17,382 system + 5,335 user characters; frame system: 13,452 characters. These are character counts, not tokens. First usable frame under 60 seconds, browser rendering and the effect of a cold Openverse search on frame latency were not measured. No browser QA in P2.

Targeted regression run: 76/76 across 13 files (semantic composition, canonical compatibility, provider and placement, planning, revision, export and transport). Additional integration run: 89/90 before restoring the explicit local asset-reference wording; the isolated affected suite then passed 27/27. The separate legacy navigation suite was not used as a clean result: its exact product-identity assertion expects no `layoutIntent`, which the pre-P2 normalization already supplies. TypeScript and targeted Biome check passed.
