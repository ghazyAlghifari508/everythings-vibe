# TASK 08 — Improve Canvas Frame Preview Sharpness at Different Zoom Levels

**Kategori:** MEDIUM–COMPLEX  
**Prioritas:** P1  
**Repository:** ghazyAlghifari508/everythings-vibe

## TUJUAN

Perbaiki kualitas visual screenshot preview VibeDesign Studio ketika user melakukan zoom-out.

Masalah:

- Pada zoom rendah, frame terasa sangat buram.
- Untuk melihat isi yang jelas, user harus zoom-in.
- Pengalaman canvas terasa kurang nyaman.
- Beberapa frame tampak lebih buram dari lainnya.

Catatan teknis:

Studio menggunakan screenshot raster dari renderer, sebelumnya dengan JPEG quality sekitar 90 dan device scale factor 2.

Jangan menganggap screenshot harus tajam seperti HTML live pada semua tingkat zoom. Tetapi jangan pula menerima blur tambahan akibat scaling, kompresi, atau pemilihan resolusi yang keliru.

Identifikasi apakah blur berasal dari:

1. JPEG compression.
2. Source resolution terlalu rendah.
3. Multiple resampling.
4. Wrong width/height.
5. Browser downsampling.
6. Aggressive preview thumbnail.
7. CSS filter/transform.
8. Screenshot aset lama dengan dimensi tidak cocok.

Jangan langsung meningkatkan semua screenshot ke resolusi 4x.

## TARGET

```
ORIGINAL PREVIEW
       |
       v

       |

       |
       +--> Zoom 25% -> Clean overview
       |
       +--> Zoom 50% -> Clean medium view
       |
       +--> Zoom 100% -> Sharp details
       |

```

Pada 25%, teks yang secara fisik hanya beberapa piksel tidak akan sepenuhnya terbaca. Namun bentuk UI, batas card, chart, dan garis tipis seharusnya tidak menjadi kabur secara berlebihan.

## SOLUTION STRATEGY

Evaluasi secara terukur:

### A. Correct scaling

Pastikan screenshot ditampilkan sesuai aspect ratio aslinya.

Jangan ada CSS yang memperbesar gambar ke dimensi yang tidak sesuai.

### B. Better encoding

Bandingkan kualitas/ukuran:

- JPEG.
- WebP.
- PNG.

Pilih berdasarkan hasil uji fixture, bukan preferensi pribadi.

Jangan menggunakan PNG untuk semua gambar jika ukuran file menjadi tidak masuk akal tanpa manfaat yang terukur.

### C. Adaptive preview resolution

Jika terbukti diperlukan, gunakan preview variants yang sesuai dengan kebutuhan canvas.

Contoh:

```
LOW ZOOM:
efficient overview image

MEDIUM/HIGH ZOOM:
higher resolution preview
```

Gunakan caching dan stable revision keys.

Jangan membuat screenshot baru setiap kali mouse wheel bergerak.

Jangan menyebabkan worker load berlebihan.

### D. Preserve existing last-good preview

Jika preview resolution variant gagal dibuat, jangan hilangkan gambar yang sudah tersedia.
