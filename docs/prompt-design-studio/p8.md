# TASK 08 — Replace "Lepas Referensi" with Click-Again-to-Deselect Behavior

**Priority:** P2  
**Complexity:** EASY–MEDIUM  
**Branch:** `feature/vibedesign-design-studio`

## Mission

Remove the redundant "Lepas referensi" action from the fullscreen Design Picker.

Allow users to deselect a selected theme/reference by clicking the selected card again.

Keep draft selection and confirmed composer state separate.

## Source Inspection

Read repository rules and inspect:

```
src/features/studio/components/design-system/studio-design-picker-dialog.tsx
src/features/studio/components/design-system/studio-design-picker-panels.tsx
src/features/studio/components/design-system/studio-scrape-design-sources.tsx
```

Inspect the parent composer state and every `onClear`, `onSelectTheme`, and `onSelectScrape` handler.

## Required Interaction

```
INITIAL

[ Workspace ] [ Editorial ] [ Midnight ]
                                  ✓
```

User clicks Midnight again:

```
RESULT

[ Workspace ] [ Editorial ] [ Midnight ]

No theme selected.
```

User selects Workspace:

```
RESULT

[ Workspace ] [ Editorial ] [ Midnight ]
       ✓
```

The interaction must be a true toggle, not an animation that leaves the old selection active internally.

## Important State Requirement

The current code derives the active theme using a pattern similar to:

```
pendingThemeId ?? selectedThemeId
```

This cannot reliably distinguish:

- No pending change.
- Explicitly cleared selection.

Audit and correct the draft-state model.

Represent these states explicitly.

For example, use a discriminated draft state or another unambiguous representation.

Do not introduce multiple booleans that can contradict each other.

## Apply and Cancel

Expected:

```
Open picker
    |
    v
Change draft selection
    |
    +--> Cancel
    |      |
    |      v
    |   Keep previous composer reference
    |
    +--> Apply
           |
           v
       Persist new selection
       OR persist no reference
```

Clicking a card should not immediately mutate the confirmed reference if the dialog is intended to support Apply/Cancel.

For saved VibeScrape references, preserve a consistent select/deselect model.

For custom uploaded [DESIGN.md](http://DESIGN.md), keep file removal explicit where needed rather than pretending clicking the upload zone can undo an existing file.

Do not accidentally clear the PRD attachment when clearing [DESIGN.md](http://DESIGN.md).

Do not accidentally delete the logo unless the intended reference-removal policy requires it and this is clearly represented.

## UI Requirements

Remove the text button:

"Lepas referensi"

Use clear selection styling:

- Selected border.
- Check icon.
- Appropriate `aria-pressed` or equivalent semantic state.
- Keyboard accessibility.

No duplicate selection summary or unnecessary confirmation modal.

When no theme is selected, the Apply button must support the intended "no reference" state rather than becoming silently unusable.

Keep copywriting short and nontechnical.
