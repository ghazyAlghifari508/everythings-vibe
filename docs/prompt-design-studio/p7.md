# TASK 07 — Fix Studio Project Naming, AI-Generated Titles, and Add Rename Project Action

**Kategori:** MEDIUM–COMPLEX  
**Prioritas:** P1  
**Repository:** ghazyAlghifari508/everythings-vibe

## MISSION

Perbaiki sistem penamaan project Studio.

User melaporkan judul project terlalu panjang dan tidak representatif.

Contoh:

```
Dashboard analitik web untuk produk SaaS
"Metriq" yang dipakai tim growth dan fi...
```

Judul tersebut adalah deskripsi kebutuhan, bukan nama project yang baik.

User juga meminta fitur `Ganti nama` melalui menu titik tiga pada history Studio.

## INVESTIGASI

Periksa repository rules dan file:

```
studio-project-enqueue.ts
studio-project-create.ts
studio-job-pipeline.ts
studio-planning.ts
studio-planning-parser.ts
studio-sidebar.tsx
studio-project-http.ts
studio-project-lifecycle.ts
studio-header.tsx
```

Cari semua jalur pembuatan/update title.

Dari audit sebelumnya:

1. Initial project title dapat berasal dari potongan prompt sekitar 80 karakter.
2. Planning AI dapat menghasilkan `projectTitle`.
3. Project title dibatasi hingga sekitar 200 karakter pada salah satu jalur.
4. Dropdown project history belum memiliki Rename.
5. Endpoint project belum memiliki dedicated rename action.

Verifikasi ulang sebelum mengubah.

## PART A — PROJECT IDENTITY

Pisahkan:

```
PRODUCT NAME:
Metriq

PROJECT TITLE:
Metriq Analytics

PROJECT DESCRIPTION:
Dashboard pertumbuhan dan keuangan SaaS.
```

Jangan gunakan deskripsi panjang sebagai header project.

### Target

SALAH:

```
[≡] Dashboard analitik web untuk produk SaaS
    "Metriq" yang dipakai tim growth dan fi...
```

BENAR:

```
[≡] Metriq Analytics
```

Jika user meminta:

"Website portfolio untuk Nadia Prameswari..."

Nama project dapat menjadi:

`Portfolio Nadia Prameswari`

Bukan:

`Website portfolio untuk Nadia Prameswari yang...`

## PART B — AI TITLE GENERATION

Perbaiki planning guidance dan validation:

- Project title singkat.
- Relevan dengan produk.
- Tidak berupa paragraf.
- Tidak menyalin seluruh prompt.
- Tidak menggunakan frasa marketing berlebihan.
- Tidak menggunakan nama generik `My Project`, `Untitled App`, atau `New Design` sebagai fallback permanen apabila identitas jelas tersedia.
- Tidak mengarang merek jika user sudah menyebut nama merek.
- Tidak mengandung deskripsi teknis yang seharusnya disimpan di metadata lain.
- Batasi panjang secara semantik, bukan hanya memotong karakter.

Jika AI planning gagal atau belum selesai, gunakan provisional title yang jelas dan aman.

Setelah hasil planning valid tersedia, update title dengan aturan yang dapat diprediksi.

Jangan menimpa nama yang sudah diubah user secara manual.

## PART C — RENAME PROJECT

Tambahkan menu:

```
┌──────────────────────────────┐
│ Ganti nama                   │
│ Duplikat project             │
│ Hapus project                │
└──────────────────────────────┘
```

Gunakan icon:

- Pencil untuk rename.
- Copy untuk duplicate.
- Trash untuk delete.

Tidak boleh menggunakan em dash pada copywriting baru.

### Rename dialog

```
┌───────────────────────────────┐
│ Ganti nama project            │
│                               │
│ Nama project                  │
│ ┌───────────────────────────┐ │
│ │ Metriq Analytics          │ │
│ └───────────────────────────┘ │
│                               │
│            [Batal] [Simpan]   │
└───────────────────────────────┘
```

Use existing Dialog/Input/Button components.

Rename harus:

- Memvalidasi nama tidak kosong.
- Menormalisasi whitespace.
- Memiliki batas karakter masuk akal.
- Menggunakan project ID yang sama.
- Memvalidasi ownership user.
- Menyimpan perubahan secara persisten.
- Memperbarui sidebar dan header.
- Tidak memulai AI generation.
- Tidak mengganti shared blueprint.
- Tidak mengubah frame HTML.
- Tidak mengubah preview.
- Tidak membuat project duplikat.
- Tidak mengubah ID/history references.

## PART D — CONCURRENCY / DATA INTEGRITY

Periksa kondisi:

- User rename saat project masih generating.
- AI planning selesai setelah user melakukan rename.
- User rename lalu refresh.
- Rename dari sidebar history.
- Multiple project names sama.
- Project dihapus ketika dialog rename masih terbuka.
- Session tidak valid.

Manual rename harus memiliki prioritas lebih tinggi daripada AI-generated title.

Gunakan existing persistence/query invalidation, jangan membuat polling khusus untuk rename.
