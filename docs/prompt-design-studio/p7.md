# FIX 07 — Remove Hourglass Loading Icon from Studio Submit Buttons

**Severity:** P2  
**Complexity:** SMALL  
**Target:** `feature/vibedesign-design-studio`  
**Execution order:** 07/08. Execute after FIX 06.

## Problem

Both Studio landing composer and canvas composer still display a spinning hourglass after submitting a prompt.

User explicitly wants a proper **circular loading spinner**, not an hourglass with rotation animation.

Previous code audit found `Loading01Icon` inside:

- `src/features/studio/components/composer/studio-launch-composer.tsx`
- `src/features/studio/components/composer/studio-composer.tsx`

This icon has a visually hourglass-like shape. Applying `animate-spin` doesn't change its silhouette.

## Desired interaction

```
IDLE
┌────────┐
│   ↑    │  Submit enabled
└────────┘
    |
    | Enter / Click
    v
SUBMITTING
┌────────┐
│   ◌    │  Circular spinner, disabled
└────────┘
    |
    +-- Success --> navigation / processing state
    |
    +-- Failure --> return to idle + useful error
```

The symbol `◌` represents an animated circular spinner, not a static dotted icon.

## Implementation requirements

2. Explore existing spinner/loading components under `src/components/ui`.
3. Explore appropriate components from shadcn/ui, HeroUI, Magic UI, React Bits, Thinking Orbs, and affectUI before creating anything new.
4. Prefer an already available circular loading icon or reusable spinner.
5. Replace the hourglass in **both** Studio composer submit buttons.
6. Use a consistent icon size, stroke, animation speed, and loading behavior.
7. Keep the loading indicator visible immediately after submit.
8. Prevent repeat submissions while the first request is pending.
9. Ensure pressing Enter does not trigger duplicate requests.
10. Maintain existing Shift+Enter behavior for adding a newline.
11. Preserve keyboard focus behavior and accessibility, including an appropriate accessible busy state.
12. Restore the original submit button on failure when the user may retry.
13. Don't introduce artificial progress or change backend generation behavior.

- No glowing orb in a 36–40px submit button.

- No hourglass anywhere in the **affected submit loading states**.
