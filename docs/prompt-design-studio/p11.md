**Complexity: MEDIUM–COMPLEX**

## Goal

Improve VibeDesign's design reference selection without changing its purpose.

Reported problems:

1. Ready-to-use theme cards look like miniature half-built dashboards rather than visual theme silhouettes.
2. Footer CTA changes awkwardly between "Gunakan Tema" and "Gunakan tanpa tema".
3. Theme palette circles have visible seams/stripes at their edges.
4. A selected theme or [DESIGN.md](http://DESIGN.md) must genuinely influence generated frames.
5. Selected state must be clear without AI-slop decorations.

## 2. Silhouette preview design

Replace detailed fake dashboards with abstract layout silhouettes.

The preview should communicate:

- Background/surface colors.
- Accent palette.
- Contrast.
- Border style.
- General density.
- Basic component geometry.

It should NOT contain fake KPI values, miniature unreadable text, small chart numbers, or generic dashboard copy.

Example:

```
+----------------------------+
| [■] [=========]            |
+------+---------------------+
| [==] | [=======] [=======] |
| [==] |                     |
| [==] | [================]  |
|      | [====] [====]       |
+------+---------------------+

Graphite
Minimal, monochrome, structured
```

All theme preview cards should share comparable silhouette geometry, using their actual theme colors.

Avoid overdesigning the preview.

## 4. Fix palette disk

Current palette implementation uses conic-gradient and a small circular border. Investigate the cause of the seams/lines.

Target:

- Perfectly circular visible shape.
- Colors fill the complete circle.
- No apparent transparent cracks.
- No unintended square corners.
- No border interfering with color edges.
- Accurate theme colors.
- Correct high-DPI rendering.

Prefer a simple robust CSS implementation. If antialiasing/seam artifacts persist, use a clipped SVG circular segmentation solution.

Do not change brand palette values just to hide rendering defects.

## 5. Correct theme CTA states

Separate applied state from draft selection.

**No applied theme and no draft change:**

User can close the picker. Do not force "Gunakan tanpa tema".

**User selects a theme:**

Show clear CTA: `Terapkan Tema`.

**A theme is already applied:**

Provide an explicit `Hapus Pilihan` action.

**User clicks an already selected theme again:**

Draft becomes unselected; no parent mutation until the user explicitly confirms the resulting change.

**User presses Batal or closes without applying:**

Keep the previously applied reference.

Example:

```
Theme Picker
-------------------------------------
[ Workspace ] [ Midnight ] [ Graphite ✓ ]

Graphite dipilih

-------------------------------------
[ Hapus Pilihan ] [ Batal ] [ Terapkan Tema ]
```

Only show actions that make sense in the current state. Do not display a misleading enabled Apply action when there is no valid change.

Avoid redundant "selected" badge, dot, and check all appearing simultaneously.
