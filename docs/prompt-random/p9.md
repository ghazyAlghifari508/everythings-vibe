# TASK 10E — Hugeicons Migration for VibeDesign Studio and VibeScrape

Repository: ghazyAlghifari508/everythings-vibe  
Prerequisites: Bagian 9 and TASK 10A integrated.

## Objective

Migrate Lucide icons in the separate Studio and Scrape domains to Hugeicons while preserving complete UI and interaction behavior.

Keep both domains architecturally independent.

## Preflight

Read [`AGENTS.md`](http://AGENTS.md), [TODO.md](http://TODO.md) Bagian 10, and applicable `.agents/rules/`.

Audit current icon usage in:

- `src/features/studio/`
- `src/features/scrape/`
- Their public route entry points.
- Shared primitives consumed by these domains.
- Relevant tests.

## Studio Migration

Migrate icons used by:

- Studio composer.
- Prompt shortcuts and carousel.
- Canvas toolbar.
- Zoom and pan controls.
- Frame actions and selection.
- Studio sidebar.
- Skill selection.
- DesignMD modal.
- Project history.
- Loading and generation states.

Do not alter:

- Floating layout.
- Canvas/frame geometry.
- Generated frame proportions.
- Shimmer animation.
- Modal centering.
- Tab sizing.
- Keyboard and mouse behavior.

## Scrape Migration

Migrate icons used by:

- URL input.
- Advanced parameter controls.
- Scrape mode selection.
- Progress/status display.
- Error feedback.
- Extracted assets.
- Crawl sitemap.
- History and result actions.
- [DESIGN.md](http://DESIGN.md) export.

Do not alter:

- Scrape progress behavior.
- Crawl or worker logic.
- Error classification.
- Asset previews.
- API contracts.
- Canonical `/scrape/*` navigation.

## Implementation Rules

Use named imports from the installed Hugeicons free pack and the canonical shared Icon primitive.

Verify every symbol before using it.

Preserve original icon placement, sizing, state, animation, and accessibility.

Do not replace icons with emoji, text placeholders, generic circles, or invented SVGs.

Do not introduce cross-domain icon registries or additional coupling between Studio and Scrape.

## Verification

Run relevant Studio and Scrape component tests, targeted Biome checks, and TypeScript validation.

No browser QA, Playwright browsers, or screenshot automation.

Commit by domain in atomic changes, push the working branch, and verify clean status.

Report migrated components, remaining icon imports, and tests.
