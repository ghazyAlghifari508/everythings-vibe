## 4. Preserve Critical Timing Semantics

Ensure:

- Remounting a completed component does not inflate its duration.
- `onSettle` is triggered according to the original lifecycle contract.
- A stage transition does not unexpectedly reset the total timer.
- Timer intervals are cleaned up.
- There are no stale closure or interval leaks.
- A failed operation never renders as successful.
- Activity text is not fabricated by a decorative animation.
- Reducer/hook extraction does not introduce extra renders or unstable subscriptions.

The current `ResizeObserver`-based label alignment must remain correct.

Preserve its cleanup and animation cancellation behavior.
