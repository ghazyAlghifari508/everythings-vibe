**Repository:** ghazyAlghifari508/everythings-vibe  
**Complexity:** HIGH  
**Priority:** P1  
**Scope:** Vite, TanStack Start, development startup, background workers, dependency optimization

## 1. Objective

Investigate and significantly improve the local development startup experience when running:

`pnpm dev:all`

The application currently takes an excessively long time to become visible and usable after opening localhost.

The objective is not merely making Vite print "Ready" sooner. The objective is reducing the actual time between starting the development command and receiving a usable application.

Preserve the complete development environment, including Studio, Scrape, and Codebase workers.

Do not tell the user to abandon `pnpm dev:all` as the solution.

Only implement evidence-based changes.

- Reduce unnecessary dependency invalidation.

- Avoid repeated asset writes.
- Reduce eager module loading.
