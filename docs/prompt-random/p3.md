# TASK 03: Remove AI-Slop Punctuation from Developer-Owned Product Copy

**Complexity:** MEDIUM  
**Scope:** Global user-facing application copy and agent writing rules

## Objective

Remove the overuse of decorative punctuation from everythings-vibe.

The user explicitly dislikes:

- Em dash: U+2014.
- Literal bullet separator: U+2022.
- Middle dot separator: U+00B7.

The application should use natural sentence structure and meaningful layout instead of repeatedly inserting decorative punctuation.

## 1. Mandatory Investigation

Read [AGENTS.md](http://AGENTS.md) and the repository's current rules/skills system.

Previous branches used `.agents/rules`, but later branches may organize instructions differently.

Update the actual active instruction system. Do not recreate obsolete rule folders.

Search for the specified characters and equivalent escaped Unicode/HTML representations across developer-owned UI content.

Audit:

- Public pages.
- Workspace screens.
- Settings.
- Billing.
- Admin.
- App-generated toast messages.
- Empty states.
- Tooltips.
- Dialogs.
- Error messages.
- Help/FAQ content.
- Pricing descriptions.
- Code-generated visible product labels.

## 2. Desired Transformations

```
BEFORE
2 Hengker · 88 Pro

AFTER
2 Hengker, 88 Pro
```

```
BEFORE
Nama pengguna · 31 Okt, 17.34

AFTER
Nama pengguna
31 Okt, 17.34
```

```
BEFORE
Masa aktif habis — sisa kredit periode lama hangus.

AFTER
Masa aktif habis. Sisa kredit periode lama hangus.
```

For missing values, use appropriate context:

- Tidak ada data
- Belum tersedia
- A simple hyphen in compact tables where appropriate

Avoid indiscriminately replacing every punctuation mark with a slash.

## 3. Important Scope Boundaries

Do not modify:

- User-authored documents.
- Generated PRD/AC/Task content.
- Existing saved AI conversations.
- User-provided prompts.
- Scraped website content.
- Third-party source material.
- Downloaded code.
- Lockfiles.
- External package assets.
- SVG geometry.
- Mathematical expressions.
- Semantic HTML list markers.
- Valid CSS status circles or icons.

This is not a database migration or global content rewrite.

Do not mutate saved user data.

## 4. Copywriting Contract

Persist a rule in the current agent instruction system requiring:

- Natural Indonesian product copy.
- No unnecessary em dash.
- No bullet/middle-dot separators in developer-authored UI labels.
- Prefer short sentences, layout, commas, or separate lines.
- Avoid technical jargon where unnecessary.
- Preserve accurate business semantics.

Do not introduce another verbose duplicate rule file.

## 5. Verification

Perform a scoped repository audit after changes.

Test relevant copy and UI components.

Report intentional exclusions rather than claiming all Unicode punctuation has been removed from every file.

Run TypeScript, Biome, and focused tests.

No browser QA at this phase.

## Definition of Done

Developer-owned application copy is free of the prohibited decorative punctuation.

User content, external content, and semantic structures remain untouched.

Future agents have an explicit rule preventing the same pattern from recurring.

Follow atomic commit and delivery rules.
