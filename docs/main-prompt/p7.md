## Implementation

For every Lucide import:

1. Identify the icon's actual semantic purpose.
2. Select a verified Hugeicons free-pack equivalent.
3. Use `@/components/ui/icon`.
4. Preserve per-context sizing and stroke overrides.
5. Preserve motion, color, active/disabled states, and accessibility.
6. Update relevant tests and source contracts.

Pay special attention to:

- Completion ticks and checklist indicators.
- Feature hierarchy and graph controls.
- Zoom in/out and canvas reset.
- Expand/collapse tree nodes.
- Task priority/status indicators.
- Kanban drag affordances and action menus.
- Generation/loading states.
- PRD revision and document actions.

## Whiteboard Safety

Do not change canvas geometry, edge paths, task node positions, zoom math, or drag calculations.

Replacing an SVG icon must not alter node layout or pointer interaction bounds.

Preserve the behavior of existing graph and task utilities.

## Quality Bar

Avoid:

- Generic icon replacements that lose meaning.
- Incorrect icon exports.
- New UI controls.
- Changes to page layout.
- Unnecessary additional wrappers.
- Duplicate icon abstraction.
- Replacing existing brand graphics.

No cross-domain refactor.
