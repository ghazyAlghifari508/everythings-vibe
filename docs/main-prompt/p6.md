# TASK 10B — Migrate Shared UI Primitives and Application Shell Icons

Repository: ghazyAlghifari508/everythings-vibe  
Prerequisite: TASK 10A integrated.

## Objective

Replace Lucide icons in shared UI primitives, global layouts, navigation, and other application-shell components with Hugeicons.

Preserve appearance, behavior, accessibility, and the established design system.

## Investigation

Read [`AGENTS.md`](http://AGENTS.md), [TODO.md](http://TODO.md) Bagian 10, and applicable `.agents/rules/`.

Audit actual icon usage in:

- `src/components/ui/`
- `src/components/layout/`
- `src/components/home/`
- `src/components/history/`
- `src/components/faq/`
- `src/components/bantuan/`
- Relevant shared component tests.

Important components include navbar, history drawer, chat input, dropdown, dialog, theme toggle, and application navigation.

Discover files from the latest source instead of relying on outdated TODO paths.

## Implementation

1. Inventory imported Lucide icons and their usages.
2. Choose semantically equivalent symbols from the installed Hugeicons free pack.
3. Verify every chosen export exists.
4. Migrate rendering through the shared `Icon` primitive.
5. Preserve existing icon size, color, hover, disabled, and active states.
6. Preserve theme toggles, menus, keyboard interactions, and tooltips.
7. Update affected tests and mocks.

Do not replace a meaningful icon with a visually unrelated symbol simply because the preferred name is unavailable.

## Interaction &amp; Visual Invariants

Preserve:

- Header height and alignment.
- Navbar spacing and navigation hierarchy.
- Dropdown/checkmark semantics.
- Dialog close behavior.
- Theme toggle state.
- History expand/collapse controls.
- Chat input actions.
- Loading/spinner animation.
- Focus rings and keyboard navigation.

Avoid increasing button sizes, padding, tab height, or card dimensions merely to accommodate the new icons.

Use the appropriate icon size for the existing context; do not force every icon to 18 px.

## Boundaries

Do not migrate domain-specific components from Greenfield, Codebase, Studio, or Scrape in this phase.

Do not replace brand logos, custom SVG artwork, or technology-specific icons unless they are genuinely Lucide imports.

Do not create a broad static icon registry or duplicate the Icon primitive.

## Verification

Run focused tests for shared components and layout behavior, targeted static checks, and TypeScript validation.

No browser QA, Playwright browsers, or screenshots.

Commit atomically, push the working branch, and report migrated files, icon mappings, and tests.
