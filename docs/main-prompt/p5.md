## Objective

Introduce the official Hugeicons React packages and create a production-quality shared icon primitive at `src/components/ui/icon.tsx`.

This phase establishes the foundation. Do not migrate the entire application yet.

## 1. Preflight

Read [`AGENTS.md`](http://AGENTS.md), [TODO.md](http://TODO.md) Bagian 10, and applicable `.agents/rules/` completely.

Inspect:

- `package.json` and lockfile.
- `src/components/ui/` conventions.
- Current Lucide usage patterns.
- TypeScript, Vite, and Vitest configuration.
- Existing shared primitives and design tokens.

Verify current official package documentation and installed TypeScript declarations before implementing.

## 2. Dependencies

Use the maintained official packages:

- `@hugeicons/react`
- `@hugeicons/core-free-icons`

Install using the current repository package manager:

`pnpm add @hugeicons/react @hugeicons/core-free-icons`

Do not install deprecated `hugeicons-react`.

Do not remove Lucide yet, because the rest of the repository still consumes it.

## 3. Icon Primitive

Create:

`src/components/ui/icon.tsx`

Use the official `HugeiconsIcon` component internally.

Recommended defaults:

- size: 18 px.
- strokeWidth: 1.5.
- color: currentColor.
- className support.
- aria-hidden support.
- optional state variants through altIcon/showAlt.

Allow explicit per-component overrides for legitimate existing requirements.

Derive icon types from the installed official package declarations, for example its actual component props, rather than inventing unavailable types.

Preserve valid SVG attributes and accessibility props where supported.

Do not add wrappers around wrappers or build a dynamic icon-name registry.

## 4. Examples of Desired Usage

Prefer explicit named imports from the icon pack:

import { Tick01Icon } from "@hugeicons/core-free-icons";  
import { Icon } from "@/components/ui/icon";

&lt;Icon icon={Tick01Icon} size={18} /&gt;;

The exact symbol must exist in the installed package.

Do not use namespace wildcard imports, large icon objects, or runtime string-to-icon mappings.

## 5. Accessibility and Rendering

Test:

- Default size and stroke.
- Explicit size/stroke overrides.
- Class and color inheritance.
- Accessible decorative/icon-only usage.
- altIcon/showAlt behavior.
- Valid SSR rendering.
- Compatibility with React 19 and strict TypeScript.

Icons do not become interactive controls by themselves. Keep click semantics on accessible buttons.

## 6. Completion

Create focused unit tests for the primitive.

Run targeted Vitest, TypeScript, and Biome checks.

No browser QA, screenshots, or Playwright browser execution.

Commit and push the isolated foundation changes, verify clean git status, and report the established API.

Do not perform any unrelated UI redesign or remove Lucide in this phase.
