# TASK 5 — Relocate Nonfatal HTML Preview Warning Below the Preview

**Repository:** `ghazyAlghifari508/everythings-vibe`  
**Branch:** `feature/vibedesign-scrape`  
**Complexity:** EASY–MEDIUM  
**Scope:** Placement and UX of nonfatal degraded preview warning only.

## 1. Masalah

Pada Scrape HTML, ketika preview sudah bisa menampilkan konten tetapi sebagian resource belum termuat sempurna, muncul informasi seperti:

"Sebagian tampilan belum termuat."

Saat ini warning muncul di bagian atas area preview dan terasa mengganggu konten website yang sedang diamati.

Saya ingin warning nonfatal berada **di bawah area preview**, bukan melayang di atas website.

Namun warning dan recovery tetap harus mudah ditemukan, terutama jika halaman website panjang.

## 2. Investigasi

Periksa HEAD terbaru, project rules, dan komponen berikut:

- `src/features/scrape/components/scrape-detail-preview-overlay.tsx`

Pada versi yang sebelumnya diperiksa, warning `degraded` diposisikan menggunakan `absolute top-3 left-3`.

Verifikasi apakah itu masih root cause posisi UI sekarang.

## 4. Behavior detail

### Nonfatal degraded

- Tampilkan warning di bawah canvas/viewport preview.
- Jangan menutupi navbar, heading, tombol, atau konten halaman sumber.
- Gunakan desain notice yang ringkas.
- Warna dan icon mengikuti existing design system.
- Jangan membuat panel warning terlalu tinggi.
- Hindari teks penjelasan panjang yang berulang.

### Long preview

Perhatikan website yang panjangnya beberapa layar.

**Jangan menaruh warning jauh sekali di bagian paling akhir dokumen sehingga tidak bisa ditemukan.**

Jika perlu, gunakan viewport preview dengan scroll internal yang benar dan footer notice terpisah di bawah visible preview area.

Namun jangan mengubah tinggi, scroll behavior, atau rendering model secara agresif. Evaluasi struktur existing terlebih dahulu agar solusi tidak mengulangi bug scroll preview yang pernah terjadi.

### Fatal error

Jangan memindahkan semua error menjadi footer.

Error fatal yang membuat konten sama sekali tidak dapat ditampilkan tetap boleh menggunakan centered error state dengan tombol **Coba lagi** yang jelas dan mudah ditemukan.

### Screenshot fallback

Pertahankan penjelasan bahwa screenshot merupakan tampilan statis, bukan interaksi live. Jangan menggandakan warning jika fallback notice sudah menjelaskan masalah yang sama.
