# TASK: Context-Aware [DESIGN.md](http://DESIGN.md) Viewer — Light/Dark Tabs and Consistent Download Filename

**Kompleksitas: MEDIUM**

## Tujuan

Perbaiki dua hal pada VibeScrape [DESIGN.md](http://DESIGN.md):

1. Ketika pengguna memilih analisis Light + Dark dan kedua tema benar-benar berhasil diidentifikasi, sediakan cara untuk melihat hasil masing-masing tema secara terpisah dalam panel [DESIGN.md](http://DESIGN.md).
2. File hasil download harus bernama tepat [`DESIGN.md`](http://DESIGN.md), bukan nama website seperti [`www.figma.com.md`](http://www.figma.com.md).

Perubahan ini hanya untuk presentasi dan file download.

Jangan mengulang atau mengubah logic pengukuran yang sedang ditangani task generator [DESIGN.md](http://DESIGN.md).

┌───────────────────────────────────────────────────┐

Posisi:

- Rendered/Source tetap di kiri.
- Light/Dark berada di ujung kanan toolbar yang sama.
- Jangan membuat navbar ketiga.
- Jangan membuat toolbar baru.
- Jangan membuat modal baru.
- Jangan mengubah dark/light mode global aplikasi.

**Switcher mengubah konteks hasil [DESIGN.md](http://DESIGN.md) yang sedang dilihat, bukan tema aplikasi everythings-vibe.**

## 3. Behavior

Jika hanya Light valid:

- Jangan tampilkan switcher yang tidak berguna.
- Tampilkan hasil Light seperti sekarang.

Jika Light dan Dark valid:

- Tampilkan segmented control Light/Dark.
- Rendered mengikuti pilihan tema.
- Source juga mengikuti pilihan tema yang sama.
- Shared design foundations tetap digunakan pada kedua konteks.
- Theme-specific overrides mengikuti tema aktif.

Jika user meminta Dark tetapi website tetap Light:

- Jangan mengarang konten Dark.
- Jangan memaksa switcher dua tema.
- Berikan informasi keterbatasan hanya jika relevan dan tidak mengganggu.
- Jangan memperlakukan requested color-scheme sebagai bukti dukungan dark mode.

Jika ada Desktop + Mobile:

- Pertahankan informasi responsive yang valid.
- Jangan membuang perbedaan viewport saat mengganti tema.
- Jangan membuat matriks empat tab kompleks tanpa kebutuhan.

## 4. Single canonical document

Walaupun viewer dapat memfilter tampilan berdasarkan tema, file download **tetap satu [DESIGN.md](http://DESIGN.md)**.

Contoh struktur file:

```
DESIGN.md
│
├── Overview
├── Shared Foundations
├── Light Theme
├── Dark Theme (if verified)
├── Responsive Variations
├── Components
├── Guidelines
├── CSS/Tailwind Tokens
└── Relevant Limitations
```

Jangan membuat file [`DESIGN-light.md`](http://DESIGN-light.md) dan [`DESIGN-dark.md`](http://DESIGN-dark.md) secara default.

Jangan sampai pilihan tab Light/Dark menyebabkan download kehilangan separuh design specification.

Periksa juga aksi Copy dan Implement ke AI Agent:

- Jika sebelumnya memakai dokumen lengkap, pertahankan perilaku lengkapnya.
- Jangan diam-diam mengirim hanya satu tema jika user tidak memilih export parsial.
- Jangan menambahkan opsi export parsial baru tanpa permintaan.

## 5. Filename

Target:

```
Source website:
https://www.figma.com/

Downloaded file:
DESIGN.md
```

Nama website tetap disimpan di metadata atau isi dokumen.

Pastikan:

- Download dari toolbar benar.
- Browser menerima nama file yang diinginkan.
- MIME type tetap sesuai.
- Extension `.md` benar.
- Filename tidak tergantung domain.
- Filename tidak tertukar dengan hasil HTML, Crawl, atau Images.
- Tidak ada success toast tambahan jika feedback yang sudah ada cukup.

## 6. Component-first requirements

Sebelum mengubah UI, WAJIB eksplorasi:

- Existing segmented/tab components.
- HeroUI.
- shadcn/ui.
- Magic UI.
- React Bits.
- Thinking Orbs: [https://www.thinkingorbs.com/#orbs](https://www.thinkingorbs.com/#orbs)
- Affect UI: [https://www.affectui.com/components](https://www.affectui.com/components)

Gunakan komponen tabs/segmented control yang sudah tersedia dan kompatibel.

**Jangan membuat segmented control custom baru dari nol jika library menyediakan solusi sesuai.**

Pertahankan design tokens, responsive behavior, accessibility, keyboard navigation, dan dark/light mode aplikasi.

Jangan memakai animasi yang tidak diperlukan.

## Definition of Done

- Theme switcher hanya muncul ketika berguna dan didukung evidence.
- Penempatannya sesuai visualisasi.
- Tidak ada navbar tambahan.
- Rendered/Source dan Light/Dark tidak saling mengganggu.
- Download selalu bernama [`DESIGN.md`](http://DESIGN.md).
- Download berisi dokumen lengkap.
- Handoff tidak kehilangan informasi.
- Tidak ada perubahan layout di luar scope.
- Tests relevan lulus.
