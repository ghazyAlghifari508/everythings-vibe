## TASK C — Select All Semantics

Must support clear and safe behavior.

Two possible scopes:

1. Select every row on the current page.
2. Select all matching results across all pagination pages.

Example:

```
☑ 10 hasil dipilih di halaman ini.

[ Pilih semua 120 hasil sesuai filter ]
```

If the second option is implemented, ensure:

- Selection is based on validated server-side filtered results.
- The user clearly sees how many results will be deleted.
- A change in filters/search does not silently expand the deletion target.
- Newly created items cannot be accidentally added to a previously confirmed selection.
- The delete operation is bound to the user's owned records.
- Server-side page size does not incorrectly limit the operation.
- Implement a bounded, safe strategy for large selections.

Do not implement fake select-all by selecting only currently loaded rows while the UI claims to select the entire dataset.

If a safe cross-page model requires more work, it must be deliberately engineered and tested, not approximated.
