# TASK: Fix Scrape History Select-All Checkbox State &amp; Visual Semantics

**Priority:** P3  
**Complexity:** Easy  
**Branch:** `feature/vibedesign-scrape`

## Goal

Perbaiki kondisi checkbox "Pilih semua di halaman ini" pada Riwayat VibeScrape.

User melaporkan checkbox menampilkan simbol minus/strip meskipun menurut user belum ada item yang dipilih.

Target:

```
0 item selected:
[ ] Pilih semua di halaman ini

Some items selected:
[-] Pilih semua di halaman ini

All page items selected:
[x] Semua hasil di halaman ini dipilih
```

Simbol strip hanya berlaku ketika sebagian item di halaman sudah dipilih.

## Investigasi

Baca [AGENTS.md](http://AGENTS.md) dan rules terkait.

Periksa:

- `src/features/scrape/components/scrape-history-select-all.tsx`
- `src/features/scrape/components/scrape-history-list.tsx`
- `src/features/scrape/hooks/use-scrape-history-selection.ts`
- Checkbox reusable atau CSS global yang memengaruhi checkbox.
- Filter/pagination selection state.

Existing component memakai native checkbox dan menghitung `selectedOnPage`.

Jangan mengasumsikan root cause sebelum memeriksa state dan styling aktual.

Perhatikan bahwa simbol strip dalam mixed state tidak selalu merupakan bug. Verifikasi apakah kondisi pada screenshot benar-benar 0 selected atau sebagian selected.

## Implementation

Pastikan:

1. Zero selected menampilkan unchecked.
2. Partial selected menampilkan indeterminate.
3. All visible page rows selected menampilkan checked.
4. Klik Select All memilih semua item halaman yang sedang terlihat.
5. Klik lagi menghapus pilihan halaman tersebut.
6. Pilihan pada halaman lain tidak menyebabkan indikasi salah pada halaman sekarang.
7. Filter dan pagination tetap mengikuti selection semantics existing.
8. Tidak ada pemilihan otomatis ketika halaman pertama dibuka.
9. Tidak ada stale selection state yang menyebabkan visual tidak sesuai.
10. Bulk actions tetap aman dan hanya mengoperasikan ID yang benar-benar terpilih.

Gunakan native checkbox atau reusable checkbox dari shadcn/ui/HeroUI yang kompatibel dengan existing implementation.

Sebelum membuat custom component, eksplorasi komponen dalam repository, Magic UI, HeroUI, shadcn/ui, React Bits, Thinking Orbs, dan Affect UI. Gunakan komponen siap pakai yang sesuai.

Jangan membuat checkbox custom dari nol.
