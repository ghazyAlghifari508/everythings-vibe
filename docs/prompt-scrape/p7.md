# TASK — SIMPLIFY IMAGES EXPLORER FILTERING

## Problem

Images Explorer currently exposes an input named "Cari gambar".

However, image cards often show:

- Preview.
- Format.
- Dimensions.
- Classification.
- Long source URL.

The user does not see a meaningful searchable image name.

The current search logic primarily matches:

- Image URL.
- HTML `alt` evidence.

This search is technically functional but difficult for ordinary users to understand or use.

The user explicitly questions its value and prefers a simpler gallery.
