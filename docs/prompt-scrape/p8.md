# TASK — FIX VIBESCRAPE BREADCRUMB ALIGNMENT

## Problem

On the VibeScrape landing page, the breadcrumb:

`Home > VibeScrape`

appears significantly farther left than the main form content.

The heading, extraction mode controls, URL input and advanced settings form a narrower centered column, while the breadcrumb follows the wider page container.

This creates visual disconnection.

The user wants the breadcrumb aligned with the main content, without turning it into another centered title or introducing a new navigation component.
