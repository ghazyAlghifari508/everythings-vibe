# TASK: Fix Misleading Crawl Depth Helper and Numeric Input UX

**Kompleksitas: EASY**

## Masalah

Di VibeScrape → Crawl Website → Parameter lanjutan → Kedalaman penelusuran, terdapat helper:

> 0 hanya mengambil halaman awal. Naikkan untuk mengikuti link lebih dalam.

Namun pesan tersebut tetap muncul ketika user mengubah angka menjadi 2 atau 3. Akibatnya, user dapat salah memahami bahwa aplikasi masih memakai kedalaman 0.

Berdasarkan pemeriksaan kode sebelumnya, helper tersebut berasal dari `src/features/scrape/types/parameter-spec.ts` dan bersifat statis.

Masalah ini harus diperbaiki tanpa redesign form.

## 1. Target

Gunakan penjelasan umum yang tidak menyesatkan, misalnya:

**Atur seberapa jauh crawler mengikuti tautan dari halaman awal.**

Contoh:

```
┌─────────────────────────────────────────┐
│ Kedalaman penelusuran                   │
│                                         │
│ [ 3                                  ] │
│                                         │
│ Atur seberapa jauh crawler mengikuti    │
│ tautan dari halaman awal.               │
└─────────────────────────────────────────┘
```

Jangan menampilkan kalimat tentang nilai 0 seolah-olah itu nilai aktif ketika user sedang menggunakan angka 3.

## 2. Audit input behavior

Periksa:

- `src/features/scrape/types/parameter-spec.ts`
- `src/features/scrape/components/scrape-workspace-parameter-group.tsx`
- `src/features/scrape/components/scrape-workspace-form.tsx`
- Zod schema dan transformasi display/internal values

Pastikan:

- Nilai 0 diterima jika memang valid menurut schema.
- Nilai 3 tetap 3 saat disubmit.
- Input kosong sementara tidak langsung dikonversi menjadi 0.
- Validasi min/max tetap benar.
- Tidak ada stale helper/error saat user mengubah angka.
- Keyboard dan screen reader tetap didukung.

## 3. Batas perubahan

- Jangan redesign parameter lanjutan.
- Jangan menambah tooltip, badge, atau card baru.
- Jangan mengubah default maxDepth tanpa alasan.
- Jangan mengubah cara kerja crawler.
- Jangan mengubah form mode lain.

Jika ternyata memerlukan komponen input baru, eksplorasi dahulu existing components, HeroUI, shadcn/ui, Magic UI, React Bits, Thinking Orbs, dan Affect UI. Gunakan komponen siap pakai yang cocok, bukan implementasi custom asal.

Namun prioritaskan mempertahankan komponen input saat ini jika hanya helper dan validasinya yang perlu diperbaiki.

## 4. Testing

Uji:

- Empty temporary input.
- Angka 0.
- Angka 1, 2, dan 3.
- Angka minimum dan maksimum.
- Nilai tidak valid.
- Submit settings.
- Copywriting helper.

**Jangan lakukan browser QA.**

## Definition of Done

- Helper tidak lagi menyesatkan user.
- Nilai input tetap sesuai angka yang dipilih.
- Temporary empty state berfungsi.
- Validasi tetap benar.
- Tidak ada perubahan UI tambahan.
- Tests dan typecheck relevan berhasil.
