Buat hasil yang ringkas dan dapat dipahami dalam beberapa detik.

Visualisasi target:

```
┌──────────────────────────────────────────────┐

│                                              │
│  Ditemukan      Tersimpan      Tidak tersedia│

│                                              │

│ • 4  Tidak dapat diakses                     │

│                                              │
│ [ Lihat rincian ▾ ]                          │
│                                              │
│ [ 23 hasil gambar yang berhasil tersimpan ]  │
└──────────────────────────────────────────────┘
```

Nilai 30/23/7 hanya contoh visual. Gunakan data aktual.

### Required Behavior

**Complete success**

- Tampilkan jumlah hasil dan galeri.
- Jangan menampilkan warning jika tidak ada masalah.

**Partial success**

- Tampilkan hasil yang berhasil.
- Tampilkan summary kegagalan secara ringkas.
- Jangan menutup atau menggantikan galeri dengan halaman error total.

**All failed**

- Jelaskan bahwa gambar ditemukan tetapi belum ada yang dapat disimpan.
- Tampilkan penyebab utama sesuai data.
- Tampilkan tindakan recovery hanya jika memang tersedia.

**No images found**

- Bedakan dari all-failed.
- Jangan mengatakan tidak ada gambar jika sebenarnya discovery gagal.

**Still processing**

- Tampilkan progress sebenarnya.
- Jangan menampilkan counter final sebelum status final atau data valid tersedia.

## 4. Failure Grouping

Kelompokkan error berdasarkan typed failure code atau metadata yang sudah tervalidasi:

- Website membatasi akses.
- Koneksi atau pemuatan gagal.
- Format tidak didukung.
- Konten ditolak oleh validasi keamanan.
- Penyimpanan tidak berhasil.
- Penyebab tidak dapat dipastikan.

Jangan mengelompokkan menggunakan pencocokan substring pada raw exception message.

Contoh:

```
7 gambar tidak tersedia
│
├── 4  Website membatasi akses
├── 2  Format tidak didukung
└── 1  Gangguan sementara
```

Jika metadata tidak memadai, gunakan fallback jujur dan singkat. Jangan mengarang penyebab.

## 5. Progressive Disclosure

Detail teknis boleh tersedia, tetapi jangan ditampilkan secara default.

Struktur:

```
[ Ringkasan hasil ]          selalu terlihat
        │
        ▼
[ Kelompok kegagalan ]       ringkas
        │
        ▼
[ Lihat rincian ▾ ]          opsional
        │
        ▼
[ Daftar gambar terdampak ]  sesuai kebutuhan
```

Pada detail satu gambar, user boleh melihat domain sumber, status, tindakan yang sesuai, dan informasi yang membantunya memahami hasil.

Jangan memuntahkan 23 URL dengan teks identik tanpa grouping.

## 7. Anti AI-Slop Rules

Utamakan information hierarchy, readability, contrast, dan actionable feedback.
