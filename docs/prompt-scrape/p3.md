## 1. Masalah

Saat user melakukan Scrape Images pada website seperti Notion, hasil pengambilan gambar bisa berjumlah puluhan sampai ratusan.

Saat ini gambar ditampilkan dalam grid panjang. User harus scroll sangat jauh untuk menemukan bagian bawah gallery.

Saya ingin **pagination yang profesional, efisien, dan menyatu dengan desain existing**, bukan infinite scroll dan bukan gallery baru.

Contoh:

- 12 gambar per halaman;
- grid desktop tetap mengikuti layout existing;
- tombol Previous / Next;
- nomor halaman;
- ellipsis jika total halaman banyak;
- informasi jumlah hasil yang akurat.

## 5. Pagination behavior

Gunakan default **12 gambar per halaman**.

Urutan data processing:

```
Semua gambar berhasil disimpan
              |
              v
         Apply filters
              |
              v
      Hitung filtered count
              |
              v
        Apply pagination
              |
              v
     Render current page only
```

Aturan:

- Pagination dilakukan setelah filter.
- Hanya card pada halaman aktif yang dirender.
- Urutan gambar existing dipertahankan.
- Jumlah total dan jumlah hasil filter harus dibedakan dengan tepat.
- Previous disabled di halaman pertama.
- Next disabled di halaman terakhir.
- Pagination disembunyikan jika hasil tidak melebihi satu halaman.
- Halaman yang tidak valid harus di-clamp ke rentang yang tersedia.
- Saat filter berubah, reset current page ke halaman pertama.
- Jika data gambar berubah akibat update status, current page tidak boleh menunjuk halaman kosong yang tidak valid.
- Filter kosong harus menampilkan empty state existing.
- Jangan tampilkan pagination untuk seluruh gambar gagal atau tidak ada gambar tersimpan.
- Status jumlah gambar ditemukan/tersimpan/gagal tidak boleh berubah karena pagination.

Tidak perlu menambahkan rows-per-page selector pada task ini. Default 12 sudah cukup.

## 7. UX details

- Pagination ditampilkan tepat setelah grid hasil.
- Tetap mudah digunakan melalui keyboard.
- Halaman aktif harus terlihat jelas.
- Button Previous/Next harus memiliki state disabled yang benar.
- Jangan menampilkan semua nomor halaman jika jumlahnya puluhan; manfaatkan ellipsis dari library.
- Gunakan label berbahasa Indonesia yang sesuai dengan UI existing.
- Hindari page transition yang berkedip atau membuat layout meloncat drastis.
- Setelah pindah halaman, posisi user sebaiknya kembali ke awal gallery, bukan ke paling atas seluruh website.
- Jika gallery sudah pendek, jangan memberi area kosong besar hanya untuk menahan tinggi.

Jika link URL halaman tidak diperlukan dan pagination hanya client-side, gunakan controlled state yang cocok dengan library tanpa membuat anchor `href="#"` yang tidak berfungsi.
