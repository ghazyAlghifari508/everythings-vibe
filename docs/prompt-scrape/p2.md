
```

                                  [Melengkapi...]
```

User tidak memahami:

- Apa yang kurang dari [DESIGN.md](http://DESIGN.md)?

- Apa yang akan dilengkapi?
- Apakah hasil sudah bisa dipakai?
- Apakah harus mengklik tombol?
- Mengapa ada status AI internal pada panel dokumen?

Berdasarkan inspeksi sebelumnya, `Melengkapi...` adalah pending state dari retry AI synthesis, bukan tombol palsu.

Namun keberadaan fungsi nyata tidak otomatis membenarkan UI yang buruk.

## 6. TASK C — Differentiate Internal Failure From Product Failure

`enrichment = unavailable`

always means [DESIGN.md](http://DESIGN.md) is materially incomplete.

Do not equate these states automatically.

For example:

- Measurements complete, narrative unavailable.
- Measurements complete, optional analysis missing.
- Missing component rules that are necessary for promised handoff.
- Invalid output document.
- Unavailable provider.
- Validation failure.

## 7. TASK D — Improve Recovery Flow

Investigate why synthesis fails and retry is needed.

Check:

- Model response format.
- Validation contract.
- Schema compatibility.
- Missing required fields.
- Unsupported design claims.
- Model timeout.
- Provider failure.
- Existing error persistence.
- Retry eligibility.
- Recovery of already-measured data.

If appropriate, move bounded automatic recovery into the processing layer rather than exposing a routine internal repair step as a public feature.

Requirements:

- Bounded retries.
- Explicit retry eligibility.
- No infinite retry loop.
- No repeated retry on every page render.
- No duplicate concurrent enrichment jobs.
- Preserve valid measured tokens.
- Preserve existing credits/quota rules.
- Respect authorization.
- Do not re-run expensive capture unnecessarily when persisted evidence is valid.
- Persist diagnostic causes securely.
- Never mark the process complete until required output is valid.
- Do not invent design rules to satisfy schema validation.

If automatic recovery is unsuitable, preserve a contextual manual recovery option only for a genuinely affected user-facing result.
