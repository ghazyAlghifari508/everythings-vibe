# TASK: Standardize Loading Spinner for Submit and HTML Preview

**Kompleksitas: EASY**

## Masalah

Terdapat inkonsistensi indikator loading pada VibeScrape.

Pada kode yang pernah diperiksa:

- `scrape-workspace-form.tsx` masih memakai `Loading01Icon` ketika submit.
- `scrape-detail-preview-overlay.tsx` masih memakai `Loading01Icon` ketika menyiapkan HTML preview.
- `scrape-detail-preview-unavailable.tsx` juga memakai ikon serupa.
- Komponen stepper menggunakan `Loading02Icon`.

Di UI, loading tersebut terlihat seperti jam pasir atau ikon yang tidak sesuai keinginan saya.

**Target: gunakan spinner circular standar dan konsisten.**

## Visualisasi

```
STATE 1 — IDLE
┌────────┐
│   ↑    │   Submit siap digunakan
└────────┘

STATE 2 — SUBMITTING
┌────────┐
│   ◌    │   Circular spinner berputar
└────────┘

STATE 3 — REQUEST ACCEPTED
Pindah ke detail progress yang sesuai.

HTML PREVIEW LOADING
┌──────────────────────────────────────┐
│                                      │
│                 ◌                    │
│       Menyiapkan tampilan...         │
│                                      │
└──────────────────────────────────────┘
```

Tidak boleh memakai ikon jam pasir.

## Instruksi

1. Telusuri seluruh penggunaan ikon yang mewakili proses loading pada VibeScrape.
2. Bedakan dengan ikon retry/refresh: ikon retry tidak perlu terus berputar saat idle.
3. Pilih satu spinner circular standar yang sudah tersedia di Hugeicons atau komponen UI proyek.
4. Pastikan spinner beranimasi saat benar-benar loading dan berhenti ketika selesai.
5. Terapkan secara konsisten pada submit, preview loading, dan retry yang sedang berjalan.
6. Pertahankan `aria-label`, status disabled, serta perlindungan duplicate-submit.
7. Hormati `prefers-reduced-motion`.

**Batas perubahan:**

- Jangan mengubah layout progress halaman.
- Jangan mengubah ukuran, bentuk, atau posisi button.
- Jangan menambahkan teks sukses/toast baru.
- Jangan membuat komponen dekoratif baru.
- Jangan merombak mekanisme loading yang akan dipulihkan di task terpisah.

Jika membutuhkan komponen baru, cari dahulu di HeroUI, shadcn/ui, Magic UI, React Bits, Thinking Orbs, atau koleksi yang sudah tersedia. Gunakan komponen siap pakai yang kompatibel; hindari implementasi custom dari nol.

## Validasi

- Test state idle, loading, success, dan error.
- Typecheck dan lint relevan.
- Pastikan seluruh loading yang ditargetkan memakai spinner circular.
- **Skip browser QA.**

## Definition of Done

- Submit menggunakan spinner circular.
- Preview HTML menggunakan spinner circular.
- Retry hanya beranimasi saat proses retry sedang berjalan.
- Tidak ada perubahan layout yang tidak diminta.
- Semua validasi relevan berhasil.
