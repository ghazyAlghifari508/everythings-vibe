# TASK: Improve VibeScrape Live Activity Feedback — Preserve Existing Progress UI

**Kompleksitas: MEDIUM**

## Konteks

Pada VibeScrape, UI loading/progress untuk Crawl Website, Generate [DESIGN.md](http://DESIGN.md), Scrape HTML, dan Scrape Images sudah berhasil dikembalikan ke desain sebelumnya.

**Saya menyukai desain progress sekarang. Jangan mengubah atau mendesain ulang UI tersebut.**

Masalah yang tersisa hanya berada pada area `Aktivitas terbaru`.

Saat ini, aktivitas hanya berupa teks yang berubah-ubah, misalnya:

- Mengambil halaman
- Menyusun analisis desain
- Memuat konten tambahan

Kadang terdapat elapsed timer. Namun, penyajian tersebut terlalu statis dan tidak memberikan feedback visual yang cukup bahwa proses sedang berjalan.

Saya ingin aktivitas terasa hidup melalui animasi subtle dan profesional, tanpa menjadikannya UI AI-slop.

## 3. Visualisasi target

SEBELUM:

```
Aktivitas terbaru

Menyusun analisis desain                         142.9s
```

SESUDAH:

```
Aktivitas terbaru

◌  Menyusun analisis desain...                   142.9s
   └─ Subtle shimmering text / animated ellipsis
```

Saat aktivitas berganti:

```
◌  Mengambil tampilan website...
                ↓
◌  Memeriksa gaya dan komponen...
                ↓
◌  Menyusun analisis desain...
                ↓
✓  Proses selesai
```

`◌` mewakili circular spinner yang benar-benar beranimasi.

Shimmer cukup pada teks aktivitas atau loading accent yang relevan. Jangan membuat tiga atau empat indikator loading dalam satu area.

## 4. Interaction &amp; animation behavior

- Spinner hanya aktif selama backend melaporkan proses berjalan.
- Tampilkan animasi yang halus, tidak berkedip agresif.
- Ketika activity label berubah, gunakan transisi pendek yang tidak menyebabkan layout shift.
- Elapsed timer tetap mempertahankan penghitungan waktu yang benar.
- Jangan me-reset timer saat teks activity berubah jika stage sebenarnya tidak berubah.
- Pada status queued, gunakan label jujur seperti `Menunggu giliran`.
- Pada completed, berhentikan animasi.
- Pada failed, jangan terus menampilkan animasi aktif.
- Pada worker stalled, prioritaskan informasi kondisi sebenarnya daripada shimmer yang seolah-olah proses masih lancar.
- Hormati `prefers-reduced-motion`.
- Pastikan `aria-live` tidak membacakan perubahan timer terus-menerus.

Jangan membuat animasi yang menyimulasikan AI reasoning atau mengarang tahap pemrosesan.

- Existing components dalam repository.
- [https://magicui.design/](https://magicui.design/)
- [https://www.heroui.com/](https://www.heroui.com/)
- [https://ui.shadcn.com/](https://ui.shadcn.com/)
- [https://reactbits.dev/](https://reactbits.dev/)
- [https://www.thinkingorbs.com/#orbs](https://www.thinkingorbs.com/#orbs)
- [https://www.affectui.com/components](https://www.affectui.com/components)

Pertimbangkan komponen shimmer, animated text, dan spinner yang sesuai.

**Gunakan komponen existing atau library yang cocok. Jangan langsung membuat komponen animasi custom dari nol.**

Jika animasi dari library terlalu dekoratif atau mengganggu aksesibilitas, pilih implementasi siap pakai yang lebih sederhana.

Jangan menambahkan dependency tanpa kebutuhan nyata.

## Definition of Done

- Aktivitas terbaru memiliki feedback animasi profesional.
- Tidak ada animasi palsu setelah proses selesai/gagal.
- Timer tetap benar.
- Status berasal dari backend asli.
- Tidak ada layout shift atau duplicate loading indicator.
- Semua desain progress sebelumnya tetap utuh.
- Komponen siap pakai telah dieksplorasi dan digunakan bila relevan.
- Automated tests relevan lulus.

Task dianggap gagal jika kamu merombak layout progress yang sudah ada.
