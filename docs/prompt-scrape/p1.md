## 3. Remove Unnecessary Technical Explanations

Hapus paragraf berikut dari primary Crawl result UI:

"Jumlah ditemukan adalah halaman yang teramati dalam batas crawl, bukan jumlah seluruh halaman website. robots.txt dihormati. Crawler membaca HTML statis tanpa eksekusi JavaScript."

Jangan menggantinya dengan:

- Accordion "Tentang Crawl".
- Tooltip "Cara kerja crawler".
- Card "Informasi teknis".
- Banner "Tentang proses".
- Paragraf disclaimer lain yang sama panjang.
- Tombol "Lihat detail analisis".

Informasi tersebut tidak perlu menjadi elemen permanen di halaman hasil.

### Critical Distinction

Menghapus teks `robots.txt` dari UI BUKAN berarti menghapus mekanisme penghormatan terhadap aturan website.

Preserve:

- robots.txt handling.
- Rate limits dan access restrictions.
- Crawl scope.
- Max pages/depth limits.
- Existing crawler behavior.
- Accurate error reporting.
- Valid technical metadata.

Informasi teknis tetap dapat disimpan pada backend/log/dokumen teknis yang memang membutuhkannya.

Jangan menghilangkan keterbatasan penting jika benar-benar memengaruhi hasil user. Komunikasikan secara singkat dan kontekstual bila diperlukan.

## 6. Copywriting Standards

Gunakan Bahasa Indonesia yang natural.

Contoh perubahan:


| Sebelumnya                        | Preferensi                               |
| --------------------------------- | ---------------------------------------- |
| `Cakupan: max 10 pages`           | `Pencarian dibatasi hingga 10 halaman`   |
| `depth 2`                         | Tidak perlu muncul pada ringkasan normal |
| `robots.txt dihormati`            | Hapus dari ringkasan                     |
| `Crawler membaca HTML statis ...` | Hapus dari ringkasan                     |
| `10 ditemukan Â· 10 berhasil`     | Statistik rapi dengan separator valid    |


Hindari campuran Bahasa Inggris/Indonesia kecuali nama fitur, teknologi, atau istilah produk memang memerlukannya.

Copy harus:

- Ringkas.
- Faktual.
- Relevan.
- Tidak ambigu.
- Tidak robotik.
- Tidak redundan.

## 7. Edge Cases

Pastikan tampilan benar ketika:

- Tidak ada halaman ditemukan.
- Hanya root berhasil diproses.
- Sebagian halaman gagal.
- Beberapa halaman dilewati.
- Semua halaman gagal.
- Crawl berhenti karena mencapai batas.
- Scope metadata tidak tersedia pada hasil lama.
- URL sangat panjang.
- Data sedang diperbarui.
- Light mode.
- Dark mode.
- Mobile viewport.

Jangan memaksakan status sukses jika hasilnya masih parsial.
