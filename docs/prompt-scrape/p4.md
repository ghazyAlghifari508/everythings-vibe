## 7. Theme switching

**Gunakan existing Light/Dark switcher. Jangan rewrite dari nol.**

Saat hasil benar-benar memiliki dua observed themes:

```
Verified LIGHT + Verified DARK
                |
                v
       [Light]  [Dark]
```

Saat dark preference menghasilkan observed light:

```
Requested DARK
       |
       v
Observed LIGHT
       |
       v
No verified Dark tab
No fabricated Dark tokens
```

Untuk contoh Notion yang dilaporkan:

- Tidak boleh memunculkan tab Dark palsu.
- Tidak boleh membuat isi Dark dengan mengubah warna secara acak.
- Tidak boleh memisahkan dua capture Light menjadi Light/Dark hanya karena request parameter.
- Penjelasan bahwa tema gelap belum terverifikasi cukup muncul secara ringkas dan kontekstual jika memang relevan; jangan membuat banner besar.

Pastikan viewer memanfaatkan verified observed appearance, bukan requested browser preference saja.
