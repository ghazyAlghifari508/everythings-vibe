# TASK: Improve [DESIGN.md](http://DESIGN.md) Typography Specimens Without Copying Website Content

**Kompleksitas: MEDIUM**

## Masalah

Pada bagian Type Scale atau Typography Inspector, contoh font saat ini mengambil teks asli dari website yang di-scrape.

Contohnya, apabila website memiliki heading:

```
Kenapa Orang Tua Memilih Genting
```

Maka tulisan tersebut langsung digunakan untuk menampilkan specimen font.

Saya ingin [DESIGN.md](http://DESIGN.md) menjadi **referensi visual yang bisa diterapkan ke berbagai aplikasi**, bukan menampilkan ulang konten website referensi.

Saya tetap ingin:

- Jenis font asli.
- Ukuran asli.
- Font weight.
- Line height.
- Letter spacing.
- Hierarchy tipografi.
- Perbedaan font antar-theme dan viewport, jika teramati.

Yang perlu berubah hanya pemilihan specimen text dan penyajian informasinya.

## 1. Investigasi jalur data

Telusuri:

## 3. Persyaratan implementasi

1. Pertahankan seluruh metadata font yang benar-benar terukur.
2. Gunakan specimen text standar berdasarkan role tipografi.
3. Pastikan ukuran sebenarnya tetap terbaca; jangan menyamakan semua role pada ukuran 16px.
4. Jika ukuran display sangat besar, gunakan scaling yang konsisten tanpa menghilangkan informasi ukuran aslinya.
5. Pastikan teks membungkus secara alami dan tidak keluar dari container.
6. Jangan mengubah hasil font family menjadi font lain secara diam-diam.
7. Jangan mengklaim sebuah font berhasil dimuat jika capture menunjukkan sebaliknya.
8. Jangan memakai heading asli website dalam specimen publik sebagai default.
9. Jika data teks asli masih dibutuhkan untuk validasi internal, pertahankan secara terpisah tanpa menjadikannya display text utama.
10. Pastikan [DESIGN.md](http://DESIGN.md) dan inspector tetap konsisten mengenai ukuran serta role typography.

## 4. Audit section lain

Periksa apakah pola menyalin teks asli juga muncul pada representasi visual lain yang sebenarnya hanya membutuhkan specimen, bukan konten website.

Jangan melakukan penghapusan massal teks website. Fokuskan perubahan pada contoh visual yang memang seharusnya netral.

Konten asli masih relevan untuk fitur Crawl atau Page Explorer, jadi jangan mengubah modul tersebut.

## 5. Aturan komponen

Jangan redesign halaman [DESIGN.md](http://DESIGN.md).

Untuk kebutuhan UI, eksplorasi dahulu komponen dari HeroUI, shadcn/ui, Magic UI, React Bits, Thinking Orbs ([https://www.thinkingorbs.com/#orbs](https://www.thinkingorbs.com/#orbs)), serta komponen proyek yang sudah dipakai. Gunakan yang paling relevan dan siap pakai.

Jika komponen typography saat ini dapat dipertahankan, cukup perbaiki sumber specimen dan styling yang bermasalah. Tidak perlu menginstal library atau membuat UI baru hanya karena ada task ini.

## 6. Validasi

Periksa:

- Display, heading, body, dan caption.
- Font size dan font weight yang berbeda.
- Font yang tidak tersedia.
- Teks panjang dan viewport kecil.
- Multiple capture.
- Konsistensi dokumen hasil download.
- Typecheck dan unit tests.

**Jangan lakukan browser QA.**

## Definition of Done

- Specimen tidak lagi menyalin copy website asli sebagai default.
- Style tetap memakai hasil pengukuran asli.
- Hierarchy font tetap jelas.
- Layout specimen tidak overflow.
- Hasil inspector dan [DESIGN.md](http://DESIGN.md) tetap konsisten.
- Tidak ada perubahan UI besar yang tidak diminta.
- Tests relevan berhasil.
