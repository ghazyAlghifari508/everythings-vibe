# Audit 002: Scrape Preview Asset Security Model & Capabilities

- **Root cause**: Preview HTML dirender di iframe `sandbox="allow-scripts"` (opaque origin, `Origin: null`, tanpa ambient cookie). Solusi inlining data-URI lama membengkakkan HTML hingga >7MB dan tetap gagal untuk font/video di atas batas payload.
- **Fix**: Resource preview direwrite ke `/api/scrape/asset?cap=<token>`; token HMAC-SHA256 (`BETTER_AUTH_SECRET`) mengikat canonical target URL + scrapeId + ownerId + expiry (TTL 1 jam). Endpoint memvalidasi tanda tangan, kepemilikan scrape dan status aktif user di DB, rate limiting, lalu mengambil aset via `fetchAsset` dengan proteksi SSRF, validasi IP publik, batas redirect, dan batas byte. Mendukung HTTP 206 range requests untuk video. Header response: `Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: sandbox; default-src 'none'`. MIME dokumen (HTML/XML) ditolak (415); SVG diizinkan sebagai image inert. CSS dan JS module di-rewrite rekursif agar nested imports memakai capability token; penanganan dynamic import diperbaiki untuk memperhitungkan offset kutip `es-module-lexer` (`d >= 0`).
- **Security boundary yang dipertahankan**: Sandbox iframe tidak diubah (tidak menggunakan `allow-same-origin`), tidak ada open proxy publik (path legacy `?url=` tetap mewajibkan session login), dan capability token tidak membawa kredensial rahasia.
- **Yang tetap utuh**: Dokumen `previewHtml` dan `DESIGN.md` yang tersimpan di database tidak diubah; fitur Copy, Download, dan export AI tetap menyajikan HTML asli.
- **Regresi yang ditemukan & diperbaiki**: Pengecekan kutip `source[s-1] !== source[e]` pada `es-module-lexer` melewati dynamic import (`import('./dynamic.js')`) yang menyebabkan code-split chunks 404 pada preview; celah validasi IPv4-mapped IPv6 bypass (diperbaiki di `0168a23`).
- **Verifikasi yang dijalankan**:
  - `pnpm test`: 209 test files passed, 2028 tests passed, 0 failed.
  - `pnpm lint`: 0 errors (10 pre-existing CSS `!important` warnings di `globals.css`).
  - `pnpm check`: 0 errors.
  - `pnpm build`: client & SSR build berhasil tanpa error.
  - `pnpm exec tsc --noEmit`: 0 errors.
  - Browser QA (Chrome DevTools) sengaja tidak dijalankan sesuai instruksi pengguna; klaim visual tidak dibuat.
- **Known limit**: Preview membutuhkan koneksi live; capability token kedaluwarsa setelah 1 jam sehingga preview tab yang di-cache client-side lebih dari durasi tersebut perlu dimuat ulang.
