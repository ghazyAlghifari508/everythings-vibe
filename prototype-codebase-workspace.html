1. Ringkasan Eksekutif

Fitur Watchlist memungkinkan pengguna terdaftar di platform movieworld-web untuk menandai film yang ingin ditonton di masa mendatang dengan sinkronisasi database akun.

2. Masalah & Solusi

Masalah: Pengguna sering lupa judul film menarik yang mereka temukan di aplikasi saat browsing.

Solusi: Tombol bookmark satu-klik di setiap kartu film dengan persistensi PostgreSQL via Drizzle ORM.

3. Kebutuhan Fungsional

  • Tombol bookmark toggle di MovieCard.tsx dan movie.$id.tsx.
  • Endpoint REST /api/watchlist dengan tenant isolation WHERE user_id = ?.
  • Toast feedback dengan durasi 4 detik dan aksi Undo.

4. Skema Data (Drizzle ORM)

export const watchlists = pgTable("watchlists", {
  id: text("id").primaryKey(),
  userId: text("user_id").notNull().references(() => users.id),
  movieId: text("movie_id").notNull(),
  createdAt: timestamp("created_at").defaultNow()
});

Acceptance Criteria (AC)

Skenario 1: Menambah Film ke Watchlist

GIVEN Pengguna telah login ke aplikasi
WHEN Pengguna mengklik ikon bookmark pada kartu film
THEN Sistem membuat baris baru di tabel watchlists, ikon aktif, dan toast sukses muncul dengan tombol Undo.

Skenario 2: Menghapus Film dari Watchlist

GIVEN Film sudah tersimpan di watchlist
WHEN Pengguna mengklik kembali ikon bookmark
THEN Sistem menghapus row dari tabel watchlists.
